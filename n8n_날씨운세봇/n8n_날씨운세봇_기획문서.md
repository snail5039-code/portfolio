# 아침 날씨·운세 알리미 (n8n + Discord) 🌤️🔮

## 프로젝트 개요

매일 아침 정해진 시간에 **오늘의 날씨**와 **오늘의 운세**를 함께 정리해서 Discord로 자동 전송해주는 n8n 워크플로우입니다. 날씨는 Open-Meteo API에서 실측 데이터를 가져오고, 운세는 개인정보(생년월일 등)를 참고해 Gemini AI가 생성합니다.

## 목표 및 의도

- ☀️ 아침마다 직접 날씨를 찾아보지 않아도 자동으로 요약해서 알려줌
- 🔮 재미 요소로 개인화된 오늘의 운세를 함께 제공
- 🤖 반복 작업(매일 확인)을 완전 자동화

## 워크플로우 구조

```
[매일 9시 20분 시작 (Schedule Trigger)]
        ├──▶ [개인정보 입력 (Set: manual)] ──┐
        └──▶ [날씨 리퀘스트 (HTTP GET)] ──────┤
                                              ▼
                                        [합침 (Merge/Combine)]
                                              │
                                              ▼
                                      [프롬프트 생성 (Set: manual)]
                                              │
                                              ▼
                          [AI Agent] ──(Chat Model: Google Gemini)
                                     ──(Memory)
                                     ──(Tool)
                                              │
                                              ▼
                                       [Discord (전송)]
```

### 1. 매일 9시 20분 시작 — Schedule Trigger
- 매일 지정 시각(09:20)에 워크플로우 실행

### 2. 개인정보 입력 — Set 노드 (Manual Mapping)
운세 생성에 참고할 개인 정보를 고정값으로 세팅:
- `name`: 이름
- `birthDate`: 생년월일 (예: 1997-05-30)
- `birthTime`: 태어난 시간 (예: 15:20)
- `gender`: 성별
- `calendarType`: 양력/음력

### 3. 날씨 리퀘스트 — HTTP Request (GET)
Open-Meteo Forecast API 호출 (대전광역시 유성구 원신흥동 좌표 기준):
```
https://api.open-meteo.com/v1/forecast?latitude=36.35&longitude=127.375&current=temperature_2m,apparent_temperature,relative_humidity_2m,precipitation,weather_code,wind_speed_10m&daily=temperature_2m_max,temperature_2m_min,precipitation_probability_max,weather_code&timezone=Asia%2FSeoul
```
받아오는 주요 값:
- `current`: 현재 기온, 체감 온도, 습도, 강수량, 날씨 코드, 풍속
- `daily`: 오늘 최고/최저 기온, 강수 확률, 날씨 코드

### 4. 합침 — Merge/Combine 노드
"개인정보 입력"과 "날씨 리퀘스트" 두 브랜치의 결과를 하나의 아이템으로 합쳐 다음 단계로 전달

### 5. 프롬프트 생성 — Set 노드 (Manual)
합쳐진 데이터를 기반으로 AI Agent에 전달할 프롬프트 텍스트를 표현식으로 조립

### 6. AI Agent
- **Chat Model**: Google Gemini Chat Model
- **Memory / Tool**: 연결되어 있으나 현재는 기본 상태(추가 확장 여지)
- 아래 시스템 프롬프트에 따라 정해진 형식으로 결과 텍스트 생성

### 7. Discord 노드
생성된 결과를 지정된 Discord 채널/웹훅으로 전송 (`sendLegacy`)

## AI 프롬프트 설계

### 역할
> 매일 아침 날씨와 오늘의 운세를 보기 좋고 간단하게 알려주는 도우미

### 입력 데이터
- **날씨 데이터**: 지역, 오늘 날짜, 현재/체감 기온, 최고/최저 기온, 강수 확률, 날씨 코드, 습도, 강수량, 풍속
- **개인정보**: 이름, 생년월일, 성별, 태어난 시간

### 날씨 코드 해석 기준
| 코드 | 의미 |
|---|---|
| 0 | 맑음 |
| 1 | 대체로 맑음 |
| 2 | 부분적으로 흐림 |
| 3 | 흐림 |
| 45, 48 | 안개 |
| 51~57 | 이슬비 |
| 61~67 | 비 |
| 71~77 | 눈 |
| 80~82 | 소나기 |
| 85, 86 | 눈 소나기 |
| 95~99 | 뇌우 |

### 출력 형식
```
🌤️ 오늘의 원신흥동 날씨
📅 날짜: {날짜}
날씨 상태 · 현재 00℃ · 체감 00℃
최고 00℃ / 최저 00℃ · 강수확률 00%
💧 습도 00% · 강수량 00mm · 풍속 00km/h
(옷차림 한 문장)
(준비물 한 문장)

🔮 {이름}님의 오늘의 운세
(오늘의 전체적인 흐름 2문장)
(일/공부 조언 1문장)
(금전/대인관계 조언 1문장)
🍀 행운의 색과 숫자
💬 오늘의 한마디
```

### 생성 규칙
- 날짜는 반드시 날씨 데이터의 오늘 날짜 사용
- 날씨 수치는 임의 변경 금지, 날씨 코드는 표에 따라 자연어로 변환
- 없는 정보는 만들지 않음
- 강수 확률 40% 이상 또는 비 관련 코드 → 우산 추천
- 체감 온도 30℃ 이상 → 더위·수분 섭취 안내
- 운세는 이름/생년월일/성별/태어난 시간을 참고해 재미 목적으로 작성 (미래 단정 금지)
- 전체 13~16줄 이내, 분석 과정·불필요한 설명 출력 금지

## 기술 스택

| 구성 요소 | 사용 기술 |
|---|---|
| 자동화 플랫폼 | n8n |
| 날씨 데이터 | Open-Meteo API (무인증) |
| AI 모델 | Google Gemini (Chat Model) |
| 결과 전송 | Discord Webhook/Bot |
| 스케줄링 | n8n Schedule Trigger (Cron: 매일 09:20) |

## 확장 가능성

- 📍 여러 지역/사용자별 개인정보를 리스트로 순회하여 다수에게 전송
- 🗓️ 특정 요일에만 실행하거나 주말/공휴일 예외 처리
- 📊 지난 운세 기록을 저장해 트렌드 확인
- 🔔 강수확률/폭염 등 특정 조건일 때만 추가 알림 발송
- 🧵 Discord 대신 카카오톡/텔레그램 등 다른 채널로 확장

## 주의사항

- ⚠️ 개인정보(생년월일 등)는 워크플로우 내에 고정값으로 저장되므로 워크플로우 공유 시 주의
- ⚠️ Discord Webhook URL, Gemini API 키 등 인증 정보는 n8n Credentials로 관리하고 노출 금지
- ⚠️ Open-Meteo 좌표는 원신흥동 대표 좌표로, 정확한 건물 위치와는 소폭 오차 있음
