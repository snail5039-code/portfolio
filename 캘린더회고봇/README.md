# 주간 캘린더 회고 리포트 봇 (n8n + Discord)

매주 일요일 저녁, 지난 한 주간 구글 캘린더에 기록된 일정을 자동으로 불러와 AI가 한 주를 돌아보는 회고 리포트를 작성해 Discord로 전송하는 n8n 워크플로우입니다.

## 핵심 아이디어

- 캘린더 일정 데이터를 근거로 시간 배분·반복 패턴을 객관적으로 분석
- 재미보다는 생산성/자기관리에 초점
- AI가 다음 주를 위한 개선 제안까지 함께 생성

## 기술 스택

n8n, Google Calendar API, Google Gemini, Discord Webhook
