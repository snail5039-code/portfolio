# 주간 캘린더 회고 리포트 봇 (n8n + Discord) 📅📝

## 프로젝트 개요

매주 정해진 시간(예: 일요일 저녁)에 **지난 한 주간 구글 캘린더에 기록된 일정**을 자동으로 불러와서, AI가 한 주를 돌아보는 회고 리포트를 작성해 Discord로 전송해주는 n8n 워크플로우입니다. 실제로 무엇을 했는지(일정 데이터)를 근거로 요약·분석하기 때문에, 앞서 만든 두 프로젝트(사주 챗봇, 날씨·운세 알리미)와 달리 "재미"보다는 "생산성/자기관리"에 초점을 맞춘 콘텐츠입니다.

## 목표 및 의도

- 🗓️ 한 주간 캘린더에 쌓인 일정을 매번 직접 들여다보지 않아도 자동으로 요약
- 🔍 일정 데이터를 근거로 한 객관적인 회고 (시간 배분, 반복 패턴 파악)
- ✍️ AI가 다음 주를 위한 개선 제안까지 함께 생성
- 🤖 반복적인 회고 작성 습관을 자동화로 대체

## 워크플로우 구조

```
[매주 일요일 21:00 시작 (Schedule Trigger)]
                │
                ▼
      [구글 캘린더 일정 조회 (Google Calendar: Get Many)]
      (기준: 지난 7일간 이벤트)
                │
                ▼
      [일정 데이터 가공 (Function/Set)]
      - 제목, 시작/종료 시간, 소요시간 계산
      - 카테고리 분류 (업무/공부/개인/약속 등 키워드 기반)
                │
                ▼
      [프롬프트 생성 (Set: manual)]
                │
                ▼
      [AI Agent] ──(Chat Model: Google Gemini)
                 ──(Memory: 지난 주 리포트 참고용, 선택)
                │
                ▼
        [Discord (전송)]
```

### 1. 매주 일요일 21:00 시작 — Schedule Trigger
- 매주 지정 요일/시각에 워크플로우 실행 (Cron: `0 21 * * 0`)

### 2. 구글 캘린더 일정 조회 — Google Calendar 노드
- 조회 범위: 실행 시점 기준 지난 7일
- 가져오는 값: 이벤트 제목, 시작/종료 시각, 설명, 참석자 수 등

### 3. 일정 데이터 가공 — Function/Set 노드
- 각 이벤트의 소요시간(분/시간) 계산
- 제목·설명의 키워드를 기준으로 카테고리 분류 (예: "회의/스터디"→공부, "약속/저녁"→개인)
- 카테고리별 총 시간, 전체 일정 개수 등 집계값 생성

### 4. 프롬프트 생성 — Set 노드 (Manual)
- 가공된 일정 요약 데이터를 AI Agent에 전달할 프롬프트로 조립

### 5. AI Agent
- **Chat Model**: Google Gemini Chat Model
- 아래 시스템 프롬프트에 따라 정해진 형식으로 회고 리포트 생성

### 6. Discord 노드
- 생성된 리포트를 지정 채널/웹훅으로 전송

## AI 프롬프트 설계

### 역할
> 한 주간의 캘린더 일정 데이터를 바탕으로 객관적이고 건설적인 주간 회고를 작성하는 도우미

### 입력 데이터
- 기간(예: 7/21 ~ 7/27)
- 이벤트 목록(제목, 시간, 소요시간, 카테고리)
- 카테고리별 총 시간 집계

### 출력 형식
```
📅 이번 주 회고 (0000.00.00 ~ 0000.00.00)

📊 일정 요약
- 총 일정 수: 00개
- 카테고리별 시간: 업무 00시간 · 공부 00시간 · 개인 00시간

✅ 잘한 점 (1~2문장)
⚠️ 아쉬운 점 (1~2문장)
💡 다음 주 제안 (1~2문장)

💬 한 줄 응원
```

### 생성 규칙
- 실제 일정 데이터에 없는 내용은 지어내지 않음
- 카테고리별 시간 수치는 집계값 그대로 사용, 임의 변경 금지
- 특정 일정이 지나치게 몰려 있으면(예: 특정 요일에 과도한 일정) 언급
- 비판보다는 개선 방향 제시 위주로 작성
- 전체 12~15줄 이내, 분석 과정 노출 금지

## 기술 스택

| 구성 요소 | 사용 기술 |
|---|---|
| 자동화 플랫폼 | n8n |
| 일정 데이터 | Google Calendar API |
| AI 모델 | Google Gemini (Chat Model) |
| 결과 전송 | Discord Webhook/Bot |
| 스케줄링 | n8n Schedule Trigger (Cron: 매주 일요일 21:00) |

## 확장 가능성

- 📈 지난 리포트를 저장해 주 단위 트렌드(시간 배분 변화) 시각화
- 🎯 목표 시간(예: 주 10시간 공부) 대비 달성률 표시
- 🔔 특정 카테고리 시간이 임계치 이하일 때 별도 알림
- 🧵 Discord 대신 노션/이메일 등 다른 채널로 확장
- 👥 여러 캘린더(팀/개인)를 합쳐 팀 단위 회고로 확장

## 주의사항

- ⚠️ 구글 캘린더 OAuth 인증 정보는 n8n Credentials로 관리하고 노출 금지
- ⚠️ 캘린더에 개인적이거나 민감한 일정이 포함될 수 있으므로, Discord 채널 공개 범위에 유의
- ⚠️ 카테고리 분류는 키워드 기반이라 완벽하지 않을 수 있음 (오분류 가능성 있음)
