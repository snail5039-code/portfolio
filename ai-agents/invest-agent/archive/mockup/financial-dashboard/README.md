# 금융 AI 투자 운영 대시보드 목업

`MOCKUP-001-I` 대시보드부터 `MOCKUP-019-I` 승인 전 근거 패킷까지 구성된 1440×900 정적 프론트엔드입니다. 모든 수치는 화면 검토용 고정 예시이며 외부 API, 데이터베이스, 인증, 계좌 또는 주문 시스템과 연결되지 않습니다.

## 실행

패키지 설치 없이 Python 표준 라이브러리로 실행합니다.

```powershell
python -m http.server 4173
```

작업공간 루트에서 실행한 다음 `http://127.0.0.1:4173/mockup/financial-dashboard/`을 엽니다. `index.html`을 직접 열어도 모든 기능이 동작합니다.

## 포함된 상호작용

- 자산 차트 위 마우스 이동 또는 이벤트 점 키보드 포커스 시 툴팁
- 첫 번째 핵심 근거 접기/펼치기
- 반려 상태 변경 후 두 결정 버튼 비활성화
- 모의승인 상태 변경 후 두 결정 버튼 비활성화
- 판단 무효 조건 3개를 키보드 또는 마우스로 펼치고, 필요한 경우 인스펙터 본문을 세로 스크롤해 확인
- 대시보드 삼성전자 행 또는 종목명으로 기업 상세 진입, 상세 헤더와 인스펙터 하단에서 복귀
- 상세 화면의 긍정·반대 근거 6개 및 예시 공시 3개 선택 시 검증 인스펙터 갱신
- 상세 가격 차트 포인트 hover 또는 키보드 포커스 시 가격 툴팁
- 승인 대기 목록의 4개 가상 주문 필터·선택·독립 반려·모의승인과 주문 상세 확인
- 에이전트 실행 기록의 결정·단계·출처 선택과 최초 제안/검증 후 결과 비교
- 투자 정책 설정의 범위 검증, 충돌 경고, DEC-1042 가상 적용 미리보기
- 주간 투자 리포트의 기간 선택, 수익률 막대·행·위험 항목 선택, 인스펙터 갱신
- 데이터 연결 상태의 연결 대상 선택, 상태 필터, 화면용 연결 점검 결과 갱신
- 모의 거래 내역의 기간·상태 필터, 선택 자동 갱신, 비용·정책·출처 한계 확인
- 리스크 알림의 심각도·카테고리 필터, 선택 자동 갱신, 원인·권장 확인·관련 화면 이동
- 알림 수신 설정의 채널 선택, 유형 토글, 심각도 기준, 화면용 테스트 미리보기
- 백테스트 요약의 기간·전략 선택, 지표·월별 결과·인스펙터 동시 갱신과 검증 한계 확인
- 전략 조정의 목표 전략 선택, 현재·목표 비중 비교, 제안 선택과 인스펙터 갱신
- 포트폴리오 변경 전/후 비교의 변화 유형 필터, 자산 선택, 비중·위험·정책 상태와 인스펙터 동시 갱신
- 승인 전 근거 패킷의 상태 필터, 결정 선택, 계산·정책·비용·출처·리스크·역할 확인과 인스펙터 동시 갱신
- 스트레스 테스트의 충격 시나리오 선택, 자산별 충격, 대응 후보와 인스펙터 갱신
- 포트폴리오 건강의 상태·그룹 필터, 운영 체크 항목 선택, 안전 고지와 인스펙터 갱신
- 세금·수수료 영향 점검의 상태 필터, 가상 주문 선택, 비용 전후 손익과 인스펙터 동시 갱신
- 사용자 승인 이력·결정 회고의 상태·메모 필터, 결정 선택, 가상 경로 비교와 인스펙터 동시 갱신
- 에이전트별 역할 상태판의 역할 상태 필터, 역할 선택, 상태·충돌 타임라인과 인스펙터 동시 갱신

## 안전 범위

- 네트워크 요청 코드 없음
- 실제 금융 데이터 및 공시 미연결
- 실제 주문 또는 계좌 연동 없음
- 실제 세금 계산, 세무 자문, 환율 조회 없음
- 실제 성과 회고, 투자 판단 평가, 투자 권유 없음
- 실제 AI 실행 상태, 외부 에이전트 연결, 자동 금융 행동 없음
- 변경 후 비중은 실제 체결 결과가 아니며 손실 회피나 수익 개선 보장 없음
- 승인 전 근거 패킷은 실제 공시·시세·계좌 검증이나 투자 권유가 아님
- 모의승인 처리는 현재 브라우저 화면 상태만 변경
