# 금융 AI 투자·검증 에이전트 — 최초 사이트 디자인 목업 기획서

> 역할 범위: 본 문서는 개발 명세가 아니라 최초 사이트 디자인 목업을 제작하고 검토하기 위한 화면 기획서다.  
> 선행 문서: `FINANCIAL_AI_AGENT_IDEA.md`  
> 현재 단계: API·DB·에이전트 구현 전에 제품의 화면 구조와 핵심 사용 경험을 먼저 확정한다.

## 1. 이번 단계의 목표

최초 목업에서는 금융 AI 서비스의 모든 기능을 보여주지 않는다. 사용자가 첫 화면을 보는 순간 다음 네 가지를 이해하도록 만드는 것이 목표다.

1. 현재 내 자산과 손익이 어떤 상태인지
2. AI가 지금 어떤 투자 행동을 제안하는지
3. 그 제안을 다른 AI가 어떻게 검증했는지
4. 내가 승인해야 할 행동이 있는지

이번 목업의 최종 산출물은 **macOS 네이티브 금융 앱 스타일의 데스크톱 대시보드 1개 화면**이다. 화면 전환 전체를 만들기보다 투자 운영 화면의 정보 구조, 시각 언어, 에이전트 흐름을 먼저 검증한다.

## 2. 최초 목업 범위

### 포함

- macOS 스타일 통합 타이틀바
- 좌측 소스 리스트형 사이드바
- 중앙 투자 운영 대시보드
- 총자산과 기간별 손익 차트
- 보유 종목 테이블
- 우측 AI 에이전트 인스펙터
- 분석 → 검증 → 승인 대기 흐름
- 사용자 승인과 반려 버튼
- 데이터 기준 시각과 검증 시각
- 라이트 모드 데스크톱 화면

### 제외

- 실제 API 연결
- 로그인과 회원가입
- 온보딩 전체 흐름
- 실제 주문 처리
- 모바일 화면
- 다크 모드 세부 시안
- 모든 메뉴의 완성 화면
- 에이전트 채팅 UI
- 랜딩 페이지와 마케팅 페이지

제외 항목은 최초 대시보드 디자인이 확정된 뒤 별도 목업 단계에서 다룬다.

## 3. 목업 기준 사용자

### 대표 사용자

- 국내 주식을 직접 관리하는 개인 투자자
- 숫자와 근거를 확인하고 싶지만 공시 전체를 매번 읽기는 어려운 사용자
- AI 추천을 그대로 믿기보다 검증 결과와 반대 근거까지 확인하려는 사용자
- 완전 자동매매보다 승인 가능한 반자동 투자 경험을 원하는 사용자

### 사용자가 화면을 여는 상황

평일 오후, 사용자는 보유 종목과 오늘의 손익을 확인하기 위해 앱을 연다. AI는 삼성전자 비중 확대를 제안했고 검증 에이전트는 수치와 출처를 확인했지만 최근 변동성 확대를 이유로 조건부 승인을 내렸다. 사용자는 우측 인스펙터에서 제안, 검증, 위험, 주문 조건을 읽고 승인 또는 반려한다.

## 4. 핵심 화면 콘셉트

### 디자인 한 줄 정의

**Apple Stocks의 시장 정보 밀도와 macOS Finder·Mail의 소스 리스트/인스펙터 구조를 결합한 투자 운영 데스크톱 앱**

### 피해야 할 표현

- 큰 둥근 KPI 카드가 반복되는 SaaS 대시보드
- 검정 배경과 네온 색상의 트레이딩 터미널
- AI를 사람 캐릭터나 채팅 말풍선으로 표현하는 화면
- 상승·하락 외에 의미 없이 남발되는 색상
- 모든 상태를 배지로 표시하는 구성
- 사용자가 이해하기 어려운 에이전트 내부 추론 노출

### 전달해야 하는 인상

- 차분함
- 신뢰 가능성
- 높은 정보 밀도
- 원문까지 추적 가능한 투명성
- 자동 실행보다 통제가 우선인 금융 도구

## 5. 목업 화면 크기

- 기준 프레임: `1440 × 900px`
- 앱 창 최소 여백: 상하좌우 24px
- 앱 창 크기: 약 `1392 × 852px`
- 사이드바: `224px`
- 우측 인스펙터: `352px`
- 중앙 영역: 나머지 가변 폭
- 타이틀바 높이: `52px`

최초 시안은 1440×900 데스크톱 한 장을 기준으로 만든다. 작은 화면 대응은 최초 시안 확정 이후 진행한다.

## 7. 타이틀바 기획

### 좌측

- macOS 창 제어점 3개
- 사이드바 접기 아이콘
- 현재 화면명 `투자 운영`

### 중앙 또는 우측

- 계좌 전환: `시뮬레이션 계좌`
- 환경 표시: `모의투자`
- 검색
- 데이터 새로고침
- 더보기

### 상태 표시

- 마지막 동기화: `오늘 14:32`
- API 장애나 데이터 지연이 있을 때만 경고 아이콘 표시
- 모의투자 표시는 항상 노출해 실거래와 혼동하지 않게 한다.

## 8. 좌측 소스 리스트 기획

```text
투자 운영
  포트폴리오                 선택
  계좌
  거래 내역

에이전트
  분석 에이전트
  검증 에이전트
  실행 에이전트
  승인 대기                  1

문서
  투자 리포트
  감사 로그

설정
  투자 정책
  데이터 연결
```

### 표현 원칙

- 각 항목은 28~32px 높이의 조밀한 행으로 구성한다.
- 선택된 항목만 옅은 시스템 파란색 배경을 사용한다.
- 아이콘은 15~16px 단색 선형 아이콘을 사용한다.
- 그룹명은 작은 회색 텍스트로 표시한다.
- 숫자는 미처리 항목이 있을 때만 우측에 표시한다.
- `승인 대기 1`이 최초 목업의 핵심 유도 요소다.

## 9. 중앙 투자 운영 화면

### 9.1 자산 요약 헤더

```text
총자산
128,450,000원          +1,042,000원 (0.82%) 오늘

투자원금 112,000,000원 · 누적손익 +16,450,000원 · 현금 18.4%
기준 시각 2026.08.25 14:32 · 마지막 검증 14:31
```

#### 우선순위

1. 총자산
2. 오늘 손익
3. 투자원금과 누적손익
4. 현금 비중
5. 데이터 기준 시각

별도 KPI 카드를 만들지 않고 하나의 연속된 헤더 영역에 위계를 두어 배치한다.

### 9.2 기간 선택

- `1일 / 1주 / 1개월 / 3개월 / 올해 / 1년 / 전체`
- 최초 선택: `3개월`
- 오른쪽 보조 선택: `자산`, `벤치마크`, `낙폭`
- 선택 상태는 작은 세그먼트 컨트롤로 표현한다.

### 9.3 자산 변화 차트

차트에는 다음 세 요소를 표시한다.

- 내 포트폴리오: 선명한 시스템 파랑 실선
- KOSPI 벤치마크: 중간 회색 선
- 매수·매도 이벤트: 선 위 작은 점

마우스를 올리면 다음을 보여준다.

```text
2026.08.12
내 포트폴리오  +6.42%
KOSPI          +3.18%
초과수익       +3.24%p
검증 후 삼성전자 10주 매수
```

차트 영역에는 불필요한 그라데이션 채우기를 사용하지 않는다. 가로 기준선과 축 텍스트는 매우 연하게 표현한다.

| 열 | 예시 | 정렬 |
|---|---|---|
| 종목 | 삼성전자 `005930` | 좌측 |
| 수량 | 120주 | 우측 |
| 평균단가 | 68,420원 | 우측 |
| 현재가 | 71,200원 | 우측 |

| 비중 | 6.65% | 우측 |
| AI 상태 | 비중 확대 검토 | 좌측 |

#### 목업용 종목

- NAVER
- KODEX 200
- TIGER 미국S&P500
- 현금성 자산

삼성전자 행을 선택 상태로 두고, 해당 선택이 우측 인스펙터와 연결되도록 한다.

## 10. 우측 AI 인스펙터

우측 인스펙터는 최초 목업에서 서비스 차별점을 가장 강하게 보여주는 영역이다.

### 10.1 헤더

```text
현재 판단
삼성전자 · DEC-1042
조건부 승인
```

- 종목명과 결정 ID를 함께 표시한다.
- `조건부 승인`은 작은 주황색 텍스트와 아이콘으로 표현한다.
- 큰 색상 배지나 성공/실패 카드로 만들지 않는다.

### 10.2 에이전트 진행 상태

```text
● 분석 완료 ─── ● 검증 완료 ─── ○ 승인 대기
  14:28            14:31             9분 남음
```

- 에이전트를 캐릭터나 채팅방으로 표현하지 않는다.
- 금융 업무 처리 단계처럼 표현한다.
- 각 단계 클릭 시 해당 산출물 위치로 이동하는 구조를 가정한다.

### 10.3 투자 제안

```text
제안
삼성전자 10주 지정가 매수
목표 비중 6.65% → 7.20%
최대 주문금액 712,000원
```

행동, 수량, 주문 유형, 비중 변화, 최대 금액을 한눈에 확인할 수 있어야 한다.

### 10.4 핵심 근거

```text
핵심 근거
영업현금흐름 전년 동기 대비 개선                 ›
부채비율이 산업 평균보다 낮음                     ›
메모리 가격 회복 구간 진입                         ›
```

각 행 우측의 화살표는 원문 근거를 열 수 있다는 의미다. 목업에서는 첫 항목을 펼친 상태의 보조 시안도 제작한다.

### 10.5 검증 결과

```text
검증 결과
재무 수치             8/8 일치
출처                   5/5 확인
정책 한도              통과

주의
최근 20일 변동성이 사용자 기준에 근접했습니다.
지정가 71,200원 이하에서만 유효합니다.
```

검증은 단순한 `통과` 표시가 아니라 무엇을 검사했고 어떤 조건이 남았는지 보여준다.

### 10.6 무효 조건

```text
판단 무효 조건
- 지정가가 71,200원을 초과할 때
- 목표 비중이 8%를 초과할 때
- 최신 정정 공시가 확인될 때
```

기본 상태에서는 접혀 있어도 되지만 승인 전 사용자가 접근할 수 있어야 한다.

### 10.7 승인 영역

```text
이 승인은 14:42에 만료됩니다.
승인 후에도 지정가를 넘으면 주문하지 않습니다.

[반려]                         [712,000원 한도 내 승인]
```

- 승인 버튼 문구에 금액이나 행동 범위를 포함한다.
- 침묵이나 화면 이탈은 승인으로 처리하지 않는다.
- 반려는 회색 보조 버튼, 승인은 시스템 파랑 기본 버튼을 사용한다.
- 승인 직전 별도 확인창이 필요한지는 인터랙션 목업에서 검토한다.

색상 값은 목업에서 대비를 확인한 뒤 확정하며, Apple 브랜드 화면을 그대로 복제하지 않는다.

### 타이포그래피

| 역할 | 크기 | 무게 |
|---|---:|---:|
| 총자산 | 30~34px | 600 |
| 화면 제목 | 15~17px | 600 |
| 본문 | 13px | 400 |
| 표 | 12~13px | 400 |
| 보조 정보 | 11~12px | 400 |
| 그룹 라벨 | 11px | 500 |

금액과 수량에는 tabular numeral을 사용한다.

### 간격과 형태

- 기본 간격 단위: 4px
- 중앙 콘텐츠 좌우 여백: 20~24px
- 표 행 높이: 38~42px
- 인스펙터 섹션 간격: 20px
- 버튼 높이: 32~36px
- 작은 컨트롤 반경: 6~8px
- 팝오버 반경: 10~12px
- 콘텐츠 컨테이너 전체를 둥근 카드로 만들지 않는다.

## 12. 목업에 사용할 고정 데이터

디자인 검토 중 숫자가 계속 변하지 않도록 최초 목업은 다음 상황으로 고정한다.

| 항목 | 값 |

## 13. 최초 목업에서 검증할 질문

### 정보 구조

- 사용자가 5초 안에 총자산과 오늘 손익을 찾을 수 있는가?
- AI의 제안과 검증 결과가 서로 다른 역할로 보이는가?
- 무엇을 승인하는지 금액과 조건이 명확한가?
- 데이터 기준 시각과 마지막 검증 시각이 눈에 들어오는가?

### 디자인

- 일반적인 웹 SaaS가 아니라 macOS 데스크톱 앱처럼 보이는가?
- 카드가 과도하게 반복되지 않는가?
- 표와 차트의 밀도가 높지만 답답하지 않은가?
- 상승·하락·경고 색상의 의미가 일관적인가?

### 신뢰와 안전

- 검증된 사실과 AI 해석을 구분할 수 있는가?
- 반대 근거와 무효 조건에 접근할 수 있는가?
- 모의투자 환경임을 놓치기 어려운가?
- 승인 만료와 가격 조건이 충분히 명확한가?

## 14. 목업 제작 순서

### 1차 — 흑백 와이어프레임

- 1440×900 전체 레이아웃
- 세 영역의 폭과 정보 우선순위
- 차트, 표, 인스펙터의 세로 비율
- 승인 버튼까지 한 화면에 들어오는지 검증

### 2차 — 라이트 모드 비주얼 목업

- 타이포그래피와 컬러 토큰 적용
- macOS 스타일 타이틀바와 소스 리스트 적용
- 차트·표·상태 아이콘 정리
- 실제 고정 데이터를 반영

### 3차 — 핵심 인터랙션 목업

- 보유 종목 행 선택
- 인스펙터 근거 펼치기
- 승인·반려
- 승인 만료
- 데이터 지연 경고

### 4차 — 리뷰 반영

- 정보 누락과 중복 제거
- 사용자 행동 우선순위 조정
- API 구현에 필요한 화면 데이터 목록 추출
- 승인된 목업을 이후 화면과 개발 명세의 기준으로 지정

## 15. 최초 목업 완료 기준

- 1440×900 기준 한 화면 시안이 존재한다.
- 총자산, 차트, 보유종목, AI 제안, 검증, 승인이 한 화면에 포함된다.
- 삼성전자 행 선택과 우측 인스펙터의 관계가 명확하다.
- 승인 대상, 최대 금액, 만료, 가격 조건이 표시된다.
- 모든 주요 수치에 기준 시각 또는 출처 접근 단서가 있다.
- 에이전트가 채팅 UI가 아닌 업무 단계로 표현된다.
- macOS 스타일이 장식이 아니라 정보 구조에 반영된다.
- 기획 리뷰 후 `승인 / 수정 후 승인 / 재설계` 중 하나로 판정할 수 있다.

## 16. 목업 확정 이후의 순서

최초 투자 운영 화면이 승인된 뒤 다음 순서로 진행한다.

1. 기업 상세 및 공시 근거 화면 목업
2. 승인 대기 목록과 주문 상세 화면 목업
3. 에이전트 실행 기록과 검증 비교 화면 목업
4. 투자 정책 설정 화면 목업
5. 주간 투자 리포트 화면 목업
6. 전체 화면 간 사용자 흐름 확정
7. 화면별 데이터 요구사항과 API 기획

API와 개발 구현 상세는 위 화면 기획이 확정된 이후에 다룬다.
