## 1. 프로젝트 목적

금융 AI의 제안, 독립 검증, 사용자 승인 과정을 투명하게 보여주는 macOS 스타일 데스크톱 목업을 제작했다. 현재 단계는 **정적 화면 추가를 멈추고 실제 금융 API 없이 프론트엔드·백엔드 연결 앱으로 전환하는 것**이며 실제 금융 데이터, 계좌, 주문, AI 실행, API 및 DB는 연결하지 않는다. 풀스택 전환 계획은 루트 `FINANCIAL_AI_FULLSTACK_PLAN.md` 요약과 `docs/fullstack/` 분할 문서로 관리한다.

React/Vite 프론트엔드 `apps/web`는 생성되어 정적 목업 19개에 대응하는 19개 화면 이전이 완료됐다. `FRONTEND-005`는 `b654282 승인 대기 행 접근성 구조 정리`로 완료·검증·커밋·푸시됐고, `GOVERNANCE-001`은 `93d9375 역할 작업 가시성 운영 규칙 강화`로 완료·검증·커밋·푸시됐다. `FRONTEND-FINAL-AUDIT` 최초 검증은 16개 화면 1440×900 하단 잘림으로 실패했지만, `FRONTEND-FINAL-AUDIT-R1` CSS 수정 뒤 검증자 19세대가 `FRONTEND-FINAL-AUDIT-R1-V`에서 최종 회귀 `통과`를 판정했다. FastAPI 백엔드는 아직 만들지 않았다. 다음 실질 개발 후보는 `/api/health` 또는 대시보드 fixture API로 좁힌 백엔드 수직 슬라이스이며, 구현 전 계획 승인 관문을 유지한다.

모든 담당자는 루트의 `AGENTS.md`를 최우선으로 따른다. 표준 순서는 `기획자 → 관리자 승인 → 구현자 → 독립 검증자 → 재작업 → 관리자 인수`이다.

### 새 관리자 세대의 사이드바 작업 생성

- 현재 작업들의 컨텍스트가 많이 찼으므로 다음 관리자는 기존 역할 작업을 계속 재사용하지 않는다.
- 관리자·기획자·구현자·검증자 중 어느 작업이든 **컨텍스트 사용량이 50%에 도달하면 해당 역할의 새 세대 작업을 생성해 인수인계한다.** 50%를 넘긴 뒤까지 장시간 작업을 계속하지 않는다.
- 컨텍스트 사용률을 직접 확인할 수 있으면 표시된 수치를 기준으로 한다.
- 정확한 사용률을 확인할 수 없으면 다음 중 하나가 나타날 때 50% 도달로 보수적으로 간주한다.
  - 대화가 여러 차례 요약되거나 이전 지시가 압축됨
  - 이미 완료한 작업을 다시 확인하거나 역할·작업 ID를 혼동함
  - 긴 도구 출력 때문에 핵심 요구사항이 누락될 위험이 커짐
  - 사용자가 컨텍스트가 많이 찼다고 알림
- 50% 도달 시 진행 중인 위험한 외부 행동을 새로 시작하지 않는다. 현재의 안전한 로컬 단계를 정리하고 `HANDOFF.md`를 최신화한 뒤 새 작업으로 넘긴다.
- 인수인계에는 현재 목표, 완료 항목, 미완료 항목, 변경 파일, Git 상태, 테스트 결과, 위험, 정확한 다음 행동을 반드시 기록한다.
- 새 작업은 사이드바에서 사용자가 직접 볼 수 있게 만들고, 이름의 세대 번호를 1 올린다.
- 새 작업이 `AGENTS.md`와 `docs/handoff/` 단계별 문서를 읽고 인수 사실을 보고한 뒤에만 이전 작업의 책임을 넘긴다. 필요한 경우에만 `HANDOFF.md` 전체를 추가로 읽는다.
- 역할 하나만 50%에 도달하면 해당 역할만 새 세대로 교체할 수 있다. 관리자가 50%에 도달하면 지휘 연속성을 위해 관리자 작업을 우선 교체하고, 다른 역할들의 잔여 컨텍스트도 함께 점검한다.
- **새 관리자가 지정되면 관리자·기획자·구현자·검증자 4개 작업을 새 세대로 만들어야 한다.**
- 네 작업은 숨은 임시 에이전트가 아니라 Codex 사이드바에서 사용자가 직접 열어볼 수 있는 별도 작업이어야 한다.
- 권장 작업명은 세대를 구분할 수 있도록 다음과 같이 정한다.
  - `금융 AI 에이전트 관리자 2세대`
  - `금융 AI 에이전트 구현 기획자 2세대`
  - `금융 AI 에이전트 구현자 2세대`
  - `금융 AI 에이전트 검증자 2세대`
- 이후 다시 컨텍스트가 찰 경우 `3세대`, `4세대`처럼 번호를 올린다.
- 이전 세대 작업은 삭제하지 않고 기록·감사·근거 확인용으로 남긴다. 사용자가 요청할 때만 보관 처리한다.
- 새 관리자 작업을 시작하는 첫 메시지는 다음 내용을 포함해야 한다.
  - `AGENTS.md` 전체 읽기와 `docs/handoff/` 단계별 문서 참조
  - 금융 AI 에이전트 관리자로서 새 역할 작업 3개 생성 및 지휘
  - 미완료 작업부터 이어서 진행
  - 실제 금융 행동과 외부 변경의 승인 경계 준수
- 새 기획자·구현자·검증자의 첫 메시지도 `AGENTS.md` 전체와 `docs/handoff/` 단계별 문서를 읽고 자신의 역할만 수행하도록 명시한다. `HANDOFF.md` 전체는 이전 세부 이력 확인이 필요할 때만 요구한다.
- 토큰 소비 절감을 위해 새 관리자와 구현 기획자 작업은 기본 모델을 `GPT-5.5`로 지정한다. 실행 중인 작업의 모델을 바꿀 수 없으면 다음 후속 지시 또는 다음 세대부터 적용한다.
- 역할 작업은 승인 팝업이 필요한 행동을 먼저 관리자에게 보고하고, 관리자가 승인·실행 지시 또는 관리자 작업에서의 대체 실행을 담당한다. 시스템이 사용자에게만 요구하는 보안 승인은 우회하지 않는다.
- 새 관리자는 새 기획자·구현자·검증자 작업에 직접 후속 지시를 보내고 결과를 기다린 뒤 다음 관문으로 넘긴다.
- 새 작업 4개의 ID가 발급되면 아래 `현재 활성 세대` 표와 이 문서 상단 역할 목록을 즉시 갱신한다.
- 새 작업 생성은 사용자에게 직접 보이는 외부 작업 생성이므로 사용자의 요청 또는 승인을 받은 뒤 수행한다. 현재 사용자는 이 세대교체 절차를 명시적으로 승인했다.

## 9. 데이터 연결·출처 상태 완료 상태

`MOCKUP-007-I` 구현과 재작업이 완료되었고 `MOCKUP-007-V4-R1` 독립 재검증은 `통과`였다. 신규 파일은 `data-connections.html`, `data-connections.css`, `data-connections.js`, `data-connections-1440x900.png`이며 대시보드, 주간 리포트, 투자 정책 화면의 `데이터 연결` 메뉴를 `data-connections.html`로 연결했다.

- 실제 API, DB, 계좌, 주문 연결은 하지 않는다.
- OpenDART, 증권사 API, 가격 데이터, 공시 데이터, 계좌 연결은 모두 `미연결` 또는 `화면용 가상 상태`로 표시한다.
- 연결 상태, 권한 범위, 마지막 확인 시각, 데이터 한계, 출처 미확인 경고를 한 화면에서 확인할 수 있게 한다.
- 기존 화면과 같은 1440×900, 223/815/352 3열 구조와 macOS 라이트 목업 톤을 유지한다.

관리자 점검에서 `node --check data-connections.js` 통과, 로컬 URL `http://127.0.0.1:4173/data-connections.html` 응답 200, 금지 키워드 `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon`, `localStorage`, `sessionStorage`, `indexedDB`, `document.cookie`, `action=`, 외부 URL 없음, 1440×900 앱 창 1392×852, 본문 815px, 우측 인스펙터 352px, 가로 오버플로 없음, 콘솔 오류 없음, `증권사` 선택과 `차단` 필터 및 `화면용 연결 점검` 상태 문구 갱신을 확인했다. 독립 검증은 아직 수신 전이다.

검증자 4세대의 `MOCKUP-007-V4` 1차 판정은 `실패`였다. 높음 문제는 가상 항목 선택 후 `차단` 필터를 누르면 숨겨진 항목의 선택 상태와 인스펙터가 유지되는 점이었다. 보통 문제는 필터명이 차단 상태만 뜻하는 것처럼 보이는 점과 `data-connections-1440x900.png` 파일 헤더가 JPEG인 점이었다. 낮음 문제는 루트 README 캡처 목록에 데이터 연결 캡처가 빠진 점이었다. 재작업으로 필터명을 `차단·미연결`로 바꾸고, 필터 적용 후 숨겨진 선택 항목이 있으면 보이는 첫 항목으로 자동 재선택되도록 수정했다. `source-row`의 잘못된 `role="row"`를 제거해 버튼 접근성을 복구했고, 캡처 파일을 실제 PNG 헤더로 변환했으며 README 캡처 목록을 보완했다. 관리자 재점검에서 `가격 데이터` 선택 후 `차단·미연결` 필터를 누르면 선택 항목이 보이는 `OpenDART 공시`로 바뀌고 인스펙터도 `OpenDART 공시`로 갱신되며, 가로 오버플로와 콘솔 오류가 없음을 확인했다. 검증자 4세대의 `MOCKUP-007-V4-R1` 재검증은 `통과`이며 남은 중대·높음·보통·낮음 문제는 없다.

## 12. 안전 및 운영 주의

- 실제 주문·매수·매도·송금·계좌 설정은 사용자 명시 승인 없이는 절대 실행하지 않는다.
- 현재 모든 화면은 시뮬레이션이며 실제 금융 판단에 사용할 수 없다.
- 비밀키, 토큰, 개인정보를 문서·커밋·화면에 넣지 않는다.
- 공개 검색이나 신규 스킬이 필요하면 후보의 출처·권한·설치 영향을 사용자에게 먼저 보고하고 승인받는다.
- 현재 별도의 신규 스킬 설치는 없다.
- 이 프로젝트에서 사용자가 `커밋`을 지시하면 별도 반대 지시가 없는 한 `commit`과 `push origin main`까지 완료하는 뜻으로 해석한다.
