## 공통 화면 규칙

- 기준 화면: 1440×900px
- 앱 창: 1392×852px, 외부 여백 24px
- 내부 열: 223px / 815px / 352px
- 타이틀바: 52px
- 라이트 모드, 얇은 구분선, 시스템 글꼴
- 큰 KPI 카드, 네온, 과도한 그림자·그라데이션, AI 채팅 UI는 피한다.
- 선택과 경고는 색상뿐 아니라 텍스트·아이콘·ARIA 상태로 표현한다.
- 모든 금융 수치와 출처는 화면용 가상 예시이며 실제 데이터로 오인되지 않게 표시한다.

## React/Vite 이전 상태

- React/Vite `apps/web`에는 위 정적 목업 19개에 대응하는 19개 화면 이전이 완료됐다.
- 사이드바의 그룹, 문구, 순서, 주요 화면 라우팅은 19개 화면 기준으로 유지한다.
- `FRONTEND-FINAL-AUDIT` 최초 검증은 1440×900 하단 잘림 문제로 `실패`였고, `FRONTEND-FINAL-AUDIT-R1` 재작업 후 검증자 19세대가 `통과` 판정했다.
- R1 검증에서 `npm run typecheck`, `npm run build`, 19개 화면 1440×900 하단 잘림 해소, 사이드바 하단 안전 고지, 새 중대/높음 회귀 없음이 확인됐다.
- 남은 낮음 후속 후보는 기업 상세 숨김 보조 텍스트 `.chart-alt`, 세금·수수료/결정 회고/역할 상태 테스트 훅 마커 내부 가로 overflow다.
