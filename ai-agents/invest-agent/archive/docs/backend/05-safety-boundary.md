# 백엔드 안전 경계

기준일: 2026-08-29 KST

## 절대 금지

`BACKEND-001`과 이후 1단계 백엔드 구현에서는 다음을 연결하지 않는다.

- 외부 금융 API
- 실제 금융 데이터
- 증권사 계좌
- 실제 주문, 매수, 매도, 체결
- 공시, 시세, 환율 조회
- AI 실행을 통한 투자 판단
- 운영 DB
- 유료 서비스 또는 배포 환경

## 금지 문자열 점검

다음 문자열이 코드에 새로 들어가면 실제 연결 의도를 의심하고 관리자에게 보고한다. 문서의 안전 설명 문맥은 예외로 보되, 코드에서는 사용하지 않는다.

```text
fetch("https://
axios.get("https://
WebSocket
Broker
KIS
OpenDART API key
real order
live trading
```

문서 검증에서는 위 문자열이 안전 설명 문맥에만 있는지 확인한다. 다음 구현 검증에서는 코드, 설정, 테스트, 예시 환경변수에 위 문자열이 실행 가능한 연결 지시로 들어가지 않았는지 별도로 확인한다.

## 응답 안전장치

- 모든 응답은 `isMock: true`를 포함한다.
- 승인·반려 응답은 `paperOnly: true`와 `executed: false`를 포함한다.
- 화면과 API 응답 모두 실제 주문이 생성되지 않았음을 표시한다.
- 수익 보장, 손실 회피 보장, 무위험 표현을 쓰지 않는다.

## 검증자 확인 기준

- 백엔드 파일에 금지 연결 문자열이 없는지 검색한다.
- 외부 네트워크 호출 코드가 없는지 확인한다.
- 실제 계좌, 주문, 체결처럼 보이는 응답 필드가 없는지 확인한다.
- 테스트가 `/api/health`의 안전 필드를 확인하는지 본다.
- 프론트가 호출하는 주소가 로컬 백엔드 범위인지 확인한다.
- 문서에 있는 금지 문자열은 안전 점검 목록으로만 쓰였는지 확인한다.
