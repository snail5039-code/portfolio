# AI 매수·매도 판단 점검 (2026-10-14, 4일차 장중)

1~3일차 모의 자동매매 기록과 지금 코드를, 공개된 매매 기준(실무 관례, 논문)과 비교했다.
어떤 숫자가 가장 좋다고 증명된 것은 아니다. 모의투자로 며칠 더 비교해야 한다.

## 1. 지금 AI가 받는 자료 (점검 전)

| 자료 | 내용 | 문제 |
|---|---|---|
| 지표 | PER, PBR, 부채비율, 매출·영업이익 증감, 60일 변동성 | 매매 시점을 볼 지표(이동평균, 추세, 시장 대비)가 없다 |
| 장중 흐름 | 최근 1분봉 30개의 시작·끝·고가·저가 | 하루 평균 체결가(VWAP)가 없고, "떨어지는 중"인지는 AI가 짐작해야 한다 |
| 시장 지수 | 오늘 등락, 1·5·20거래일 등락, 연속 하락 | 지수가 이동평균 위인지 아래인지(시장 국면)는 없다 |
| 보유 정보 | 수량, 평균 매입가 | 세금·수수료를 뺀 손익은 없다 (작은 이익에도 팔아 비용만 낼 수 있다) |
| 일별 종가 | DB에 10/8까지 | 공공데이터 시세는 다음 영업일 오후에 올라오는데 수집이 07시뿐이라 늘 이틀 묵었다 |
| 급등 후보 | 거래대금·상승률 상위 그대로 | 이미 크게 오른 종목을 따라 살 수 있다 |

## 2. 비교한 기준

| 기준 | 내용 | 근거 | 이 앱 |
|---|---|---|---|
| 종목 추세 필터 | 20·60일 평균 위, 20일 평균이 오르는 중일 때 산다 | 실무 관례 (단독 검증 논문은 미확인) | **추가**: `trend:` 출처 |
| 시장 국면 | 지수가 장기 평균 아래면 매수를 줄인다 | Faber (낙폭을 줄이는 효과, 수익 자체는 아님) [cxoadvisory](https://www.cxoadvisory.com/?p=1115) | **추가**: 지수 20거래일 평균 대비 |
| 떨어지는 칼날 | VWAP 아래이고 저점이 계속 낮아지면 사지 않는다 | 실무 관례 | **추가**: 자동매매 매수는 코드가 막는다 |
| 장 초반 패닉 매도 | 첫 30분 움직임은 이어지지 않았다 (KOSPI 809종목, 2011~2020) | [KAIST](https://koasas.kaist.ac.kr/handle/10203/294938) | 10/14 아침 반영 (손절선만) |
| 급등 따라가기 | 한국 개별 종목은 급등 뒤 되돌림이 우세 (1983~2023) | [NISC 초록](https://nisc.com/products/abstracts/38749) | **추가**: +10% 이상 오른 종목은 후보에서 뺀다 |
| 비용 포함 손익 | 매도 세금 0.20%, 사고팔 때 수수료 | 세법 (2026 세율은 원문 재확인 필요) | **추가**: 세후 손익 |
| LLM 숫자 약점 | LLM 에이전트 대부분이 매수 후 보유를 못 이겼다. 계산·중요도 판단이 약하다 | [StockBench](https://arxiv.org/abs/2510.02209), [FinMem](https://arxiv.org/pdf/2311.13743) | 새 값도 전부 코드가 계산하고 AI는 인용만 |
| 뉴스를 사실로 | 검색한 보도를 사실로 받아들여 오류가 커진다 | [TrustTrade](https://arxiv.org/html/2603.22567v1) (심사 전) | 10/14 아침 반영 (보도 기반 추론) |
| ATR 손절, 따라 올라가는 손절 | 매입가 −k×ATR, 최근 고점 −3×ATR | [O'Neil CAN SLIM](https://en.wikipedia.org/wiki/CAN_SLIM), Chandelier Exit | **보류**: 고가·저가 일봉이 없어 ATR을 못 구한다. 며칠 데이터를 더 보고 정한다 |
| 위험 기준 수량 | 거래당 계좌의 1% 위험 | 실무 관례 | **보류**: 지금은 종목당 살 총액 35% 상한만 |
| +1R 절반 이익 실현 | 손절폭만큼 오르면 절반 팔고 손절선을 본전으로 | Van Tharp R 배수 | **보류** |
