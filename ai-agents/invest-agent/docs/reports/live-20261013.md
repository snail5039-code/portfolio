## 2. 판단을 돌아보면 (사후 계산)

- **하루 결과는 코스피보다 3.7%p 덜 빠졌다.** 하지만 대부분은 현금 비중 덕이다
- **팔지 않고 들고 있었으면 더 나았다**: 세 종목 모두 장중 저점 근처에서 팔았고 종가가 더 높았다. 보유했다면 약 7.9만 원(약 0.9%p) 덜 잃었다 (현대건설 +8,800, NH +30,600, 셀트리온 +39,800, 세금 전)
  - 원인: 09:07 시초가 급락 때 바로 묻는 규칙(종목 −3%, 시장 급락)이 공포 구간에서 매도를 끌어냈다. 반등 가능성을 따지는 근거가 약했다
- **"절반 매도"는 동작했다**: AI가 한 번에 다 팔지 않고 나눠 팔았다 (NH 3번, 셀트리온 3번)
