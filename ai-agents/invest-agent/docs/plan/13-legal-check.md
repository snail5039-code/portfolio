# 4-0 실전 전환 전 법률·약관 확인 (공개 자료 정리)

**법률 자문이 아니다.** 2026-10-09에 공개 자료를 찾아 정리한 것이다. [1차]는 정부·회사 공식 자료, [2차]는 법무법인 뉴스레터·언론 기사다. 확인하지 못한 것은 `미확인`, 해석은 "(해석)"으로 표시했다. 실전 전환과 공개 배포 전에 마지막 장의 질문을 사람이 직접 확인하거나 전문가에게 묻는다.

## 1. 자문·유사투자자문·일임

- 투자자문업: 투자 판단에 관해 자문에 응하는 일을 영업으로 하는 것. 투자일임업: 투자 판단의 전부나 일부를 맡아 투자자별로 운용하는 것을 영업으로 하는 것 (자본시장법, 현행 조문 번호 `미확인`)
- 유사투자자문업(제101조): 불특정 다수에게 대가를 받고 개인별로 맞추지 않은 조언. 금융위 신고 대상
- 2024-08-14 시행 개정 [1차] https://fsc.go.kr/po010101/82887
  - 유사투자자문업자는 단방향 채널(답장할 수 없는 채팅방, 푸시 등)로만 조언할 수 있다
  - 유료 회원과 양방향으로 주고받으면 투자자문업으로 본다. 등록 없이 하면 3년 이하 징역 또는 1억 원 이하 벌금
  - 광고 의무 고지 3가지와 손실 보전·이익 보장·거짓 수익률 광고 금지 (5장)
- 이 앱은 사용자가 묻고 AI가 그 사용자에게 맞춘 매수·매도 제안서를 쓴다. 양방향이고 개인별이라 유사투자자문업 틀에 맞지 않을 가능성이 크다 (해석)
  - 본인만 쓰는 개인 도구: 남에게 하는 자문도, 영업도 아니어서 규제 대상이 아니라는 설명이 일반적이다. 공식 유권해석은 `미확인`
  - 무료 공개 앱: 개정 단서는 "대가를 낸 고객" 기준이라 바로 걸리지는 않지만, "영업으로"에 해당하는지는 따로 따져야 한다 (광고 수익, 나중의 유료화). `미확인`, 전문가 확인 필요
  - 유료 앱: 투자자문업 등록이 필요할 가능성이 매우 크다
- 로보어드바이저 테스트베드(코스콤): 등록된 자문·일임업자를 전제로 한다. 개인 개발자가 등록 없이 쓰는 길은 아니다 (해석) [1차] https://www.fsc.go.kr/po010105/72307

## 2. 자동매매와 투자일임

- 금감원 자료는 프로그램이 종목을 자동으로 정하고 다른 사람 계좌에 연결해 매매하게 하면 미등록 투자일임으로 본다 (자동매매 프로그램 판매, 카피트레이딩, "AI 자동매매" 사례) [2차]
- 이 앱 (해석)
  - 개발자 본인 계좌·본인 규칙: 자기 매매라 일임이 아니다
  - 공개 배포: 키와 주문이 폰에 있다는 것만으로 일임에서 벗어나지 않는다. 기준은 **누가 투자 판단(종목·시점·수량)을 하느냐**다
  - 건마다 사람이 승인하는 주문은 자문 쪽에 가깝고, "AI가 고르고 한도 안에서 자동 실행"은 일임으로 볼 위험이 크다
- 그래서 실전 자동매매(4-3)는 **개발자 본인 계좌에서만**, 사용자가 매일 계획을 승인하는 소액으로 둔다. 공개 배포판에 넣을지는 전문가 확인 뒤 정한다

## 3. 증권사 Open API 약관

- KIS Developers [1차] https://apiportal.koreainvestment.com/provider
  - 개인이 본인 자산을 자기 전략으로 매매하는 것은 신청만으로 쓸 수 있다
  - 제3자 서비스(앱 배포) 제휴는 법인 대상이고, 주문 API 제휴는 제도권 금융회사(투자일임·자문업)만 된다. 그 밖은 혁신금융서비스를 검토하라고 안내
  - 앱 화면에 시세를 보여주려면 KRX 등과 정보이용계약이 필요하다
  - 각 사용자가 본인 키를 넣는 방식이 "제3자 서비스 제공"인지는 `미확인` (서면 문의 필요)
  - 호출 한도: 실전 초당 20회, 모의 초당 2회라는 자료가 있으나 공식 공지는 `미확인`
- KB증권 Open API (개인용): 2026-07-20 개인 오픈베타 시작, 시세·주문·정정·취소·잔고·체결 조회, 11월까지 범위 확대 계획 [2차] https://www.smarttoday.co.kr/ko-kr/articles/110079
  - 포털 https://openapi.kbsec.com 약관 링크가 열리지 않음. 개인 이용 조건, 제3자 배포, 자동주문 제한, 호출 한도, 모의 API, **주문 TR 명세 모두 `미확인`**
  - 공식 예제(github.com/kbsecurities/kb-openapi)는 운영 서버(`developer.kbsec.com:32484`)만 있고 주문 예제는 보이지 않음 (2026-10-09)

## 4. 개인정보 처리방침

- 근거: 개인정보 보호법 제30조, 시행령 제31조, 개인정보위 「처리방침 작성지침」 (2026년 4월 개정본이 최신)
- 법정 항목: 처리 목적, 처리 항목, 처리·보유 기간, 제3자 제공·처리 위탁(해당 시), 파기, 정보주체 권리와 행사 방법, 안전성 확보 조치, 자동 수집 장치, 보호책임자, 권익침해 구제, 변경 사항, 국내대리인·가명정보(해당 시)
- 2026 지침에서 이 앱과 관련된 것: 대화 기록 저장 사실, AI 학습 활용 여부와 거부 방법(Gemini API 정책 확인), 부적절한 답변 신고 방법, 민감정보 입력 주의 안내, 폰에서만 처리하는 정보(증권사 키)의 안내
- 이 앱이 서버에 두는 것: 이메일, 투자성향 퀴즈 답, 나이대, 계좌 요약(계좌번호 없음), 주문 기록, 대화 기록, FCM 토큰. 위탁·국외 이전 고지 후보: Google(Gemini, FCM), 서버 호스팅
- 금융 정보는 개인정보 보호법상 민감정보가 아닌 것으로 알려져 있으나, 주문 기록·잔고가 신용정보법 적용 대상인지는 `미확인`

## 5. 주의 문구

- 유사투자자문업자 광고 의무 고지 (2024-08-14): 개별 상담·자금 운용 불가, 원금 손실 가능과 손실은 투자자 부담, 정식 금융투자업자가 아님 [1차]
- AI 기본법 (2026-01-22 시행): 생성형 AI 서비스임을 미리 알리고 생성물임을 표시. 과태료 부과는 1년 유예 [2차]
- 앱이 어떤 지위든 "원금 손실 가능, 손실은 이용자 부담, AI가 생성한 정보, 정식 금융투자업자 아님" 문구를 넣는 것이 안전하다 (의견)

## 6. 사람이 직접 확인하거나 전문가에게 물을 것

1. 개발자 본인 계좌에서만 실전으로 쓰는 것은 신고·등록 없이 되는가? KIS·KB 개인 약관상 본인 프로그램의 자동주문이 허용되는가?
2. 무료 공개 배포에서 AI가 사용자별 매수·매도 의견을 주면 투자자문업 "영업"인가? 광고·유료화를 하면 달라지는가?
3. 유료라면 투자자문업 등록, 유사투자자문업 신고, 혁신금융서비스 중 어느 길이 현실적인가? 등록 요건은?
4. 사용자가 켜고 한도를 정해도 AI가 종목·시점을 정하는 자동매매는 투자일임인가? 공개판에서는 빼거나 "사용자가 정한 규칙만 실행"으로 바꿔야 하는가?
5. 각 사용자가 본인 키를 넣는 방식이 증권사 약관의 "제3자 서비스 제공"인가? (KIS·KB에 서면 확인)
6. 사용자 본인 키로 받은 시세를 그 사용자에게만 보여주는 것도 KRX 정보이용계약 대상인가?
7. KB 개인 API: 약관 본문, 호출 한도, 모의 API, 자동주문 허용 여부, 주문 TR 명세
8. 개인정보 처리방침: 보유 기간, Gemini·FCM 국외 이전·위탁 고지, AI 학습 활용 여부·거부 절차. 주문 기록·잔고가 신용정보법 대상인가?
9. AI 기본법 사전 고지·생성물 표시, 손실 가능 문구를 어느 화면에 어떤 문구로 넣을지, 앱스토어 금융 앱 심사 요건
10. AI의 잘못된 제안이나 앱 오류로 손실이 났을 때 개발자 책임과 면책 약관의 효력 (특히 공개 배포)

## 이 문서에 따라 정한 것 (2026-10-09)

- 실전 자동매매는 개발자 본인 계좌에서만 쓰는 것을 전제로, 앱이 켜져 있을 때만, 모의보다 작은 한도로 둔다 (사용자 결정)
- 실전 주문은 KB증권으로 한다 (사용자 결정). KB 주문 명세가 확인되기 전까지 실전 주문 코드는 "준비 중"으로 두고 켤 수 없게 한다
- 공개 배포(6단계) 전에는 위 질문 2~10을 반드시 확인한다
