# 출퇴근 생존일지 - 초기 텔레그램 봇 기획

매일 출근·퇴근·조퇴·휴가·결근 등 근태를 텔레그램 봇에 기록하면, 실시간 교통 상황 기반 경로를 안내하고 누적 기록에 따라 배지를 지급하는 개인용 출퇴근 기록봇 기획입니다.

> 이 기획은 이후 텔레그램 봇이 아닌 **웹 서비스**로 구현됐고, 지금은 근무시간 산정과 정정·휴가·재택 승인, 월 마감까지 다루는 **근태 관리 시스템**으로 발전했습니다. → [출퇴근 생존일지](../commute-battle)

## 핵심 아이디어

- 실시간 지연 정보를 포함한 출퇴근 경로 자동 안내
- 출퇴근을 "작전 수행"처럼 게임화하고 배지 시스템으로 꾸준함을 강화
- 타마고치식 캐릭터 성장 + 선톡으로 매일 쓸 이유를 만드는 것이 핵심
- 완료 처리는 텍스트 입력부터 안정화한 뒤 GPS 자동감지(geofence)를 옵션으로 추가

## 기술 스택 (예정)

Telegram Bot API, 실시간 길찾기 API, GPS/Geofence

## 기획에서 달라진 점

- 텔레그램 봇 → Next.js 웹 서비스 + PWA·Windows 앱
- 개인 기록봇 → 워크스페이스 기반 조직 근태 시스템(부서·직급·부서장 승인 라인)
- 배지·캐릭터 성장은 그대로 남기고, 근무시간 계산·휴가·월 마감이 중심 기능으로 추가
- GPS 자동감지 아이디어는 출근 위치 인증(지오펜스)으로 실제 구현
