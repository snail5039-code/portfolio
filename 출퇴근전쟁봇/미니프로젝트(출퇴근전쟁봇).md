# 출퇴근전쟁봇 (텔레그램) 🚨🏃

## 프로젝트 개요

**출퇴근전쟁봇**은 매일 출근·퇴근·조퇴·휴가·결근 등 근태를 텔레그램 봇에 기록하면, 실시간 교통 상황 기반 경로를 안내하고 누적 기록에 따라 배지를 지급하는 개인용 출퇴근 기록봇입니다. 단순 API 조회봇이 아니라, 게임 같은 "작전" 컨셉과 배지 수집 요소로 매일 쓸 이유를 만드는 게 핵심입니다.

## 목표 및 의도

- 🚉 매일 아침 직접 길찾기 앱을 켜보지 않아도 실시간 지연 정보 포함한 경로를 자동 안내
- 🎮 출퇴근이라는 반복적이고 지루한 행위를 "작전 수행"처럼 게임화
- 🏅 배지 시스템으로 꾸준함(연속 출근, 정시 출근 등)을 긍정적으로 강화
- 🥚 타마고치식 캐릭터 성장으로 "오늘도 출근했더니 캐릭터가 컸다"는 재미 추가
- 💬 캐릭터가 먼저 말 거는 선톡으로 진짜 키우는 존재처럼 느껴지게 함
- 🧘 조퇴·병가·휴가를 부정적 기록이 아닌 "회복·자기관리"로 존중하는 톤 유지
- 📊 나의 출퇴근 패턴(소요시간, 지각률, 생존율)을 통계로 돌아볼 수 있게 함

## 핵심 기능 (MVP)

1. **출퇴근 경로 안내** — 실시간 교통 상황 반영 경로 및 예상 소요시간
2. **근태 기록** — 출근/퇴근/조퇴/휴가/결근 기록 및 수정·삭제 (텍스트 입력 또는 GPS 자동감지, 아래 "완료 처리 방식" 참고)
3. **통계** — 주간/월간 출퇴근 리포트
4. **배지 획득 및 조회** — 누적 기록 기반 배지 시스템
5. **캐릭터 성장** — 타마고치식 레벨/진화 시스템 (아래 "캐릭터 성장 시스템" 참고)

### 완료 처리 방식: 텍스트 vs GPS 자동감지
근태 완료(도착) 처리는 두 가지 방식을 모두 지원합니다.
- **텍스트 입력**: 사용자가 직접 "도착"을 입력
- **GPS 자동감지**: 사용자가 위치공유(Live Location)를 켜두면, 목적지(집/회사) 반경 진입 시 자동으로 "도착" 처리 (geofence)

두 방식은 같은 기록 구조를 공유하고 완료 트리거만 다릅니다. **개발 순서는 텍스트 입력부터 안정화한 뒤, GPS 자동감지를 옵션(설정에서 On/Off)으로 얹는 순서**로 진행합니다.

## 사용자 흐름 예시

### 출근
```
사용자: 출근

🚨 제14차 도시 진입 작전
비로 인해 도보 구간 난이도가 상승했습니다.
평소보다 8분 빠른 08:12 출발을 권장합니다.

출근 경로
지하철 41분 · 버스 48분
예상 도착: 08:53

출발하면 출발을 입력해주세요.
```

### 도착
```
사용자: 도착 (또는 GPS 자동감지)

✅ 출근 작전 완료
소요 시간 39분 · 예상보다 2분 단축
연속 출근 5일째입니다.

🐣 +15 EXP (기본 10 + 정시보너스 5)
Lv.6 → Lv.7 (다음 레벨까지 12 EXP)

🏅 새로운 배지 획득
월요일의 생존자
월요일 출근 작전 5회 완료
```

### 우회 제안 (지연 감지 시)
```
🚨 2호선 신호 지연으로 6분 늦어지고 있어요.
버스 환승 경로로 가면 4분 더 빠를 것 같은데, 우회할까요?

[네, 우회]  [아니요, 기존 경로]
```
- "네" 선택 → 해당 경로로 안내 전환, 배지/통계도 실제 이용 경로 기준 기록
- "아니요" 선택 → 기존 경로 유지, 지연 시간은 참고 정보로만 안내
- 제안 기준: 대안 경로가 현재 기준 **5분 이상** 빠를 때만 제안 (너무 잦은 제안 방지)

## 근태 명령어

| 명령어 | 설명 |
|---|---|
| 출근 | 출근 작전 시작 (경로/난이도 안내) |
| 퇴근 | 귀가 경로 조회 및 퇴근 기록 시작 |
| 도착 | 진행 중인 이동 완료 처리 |
| 조퇴 | 조퇴 사유를 선택적으로 기록 |
| 결근 | 결근 기록 |
| 휴가 | 연차·반차(오전/오후 구분)·병가 등록 |
| 취소 | 잘못 입력한 당일 기록 취소 |
| 기록 | 이번 주·이번 달 근태 확인 |
| 배지 | 획득한 배지 목록 조회 |
| 내정보 | 누적 출퇴근 횟수와 통계 |
| 등록 | 집/회사 주소 최초 등록 |
| 주소변경 | 등록된 주소 변경 |
| 내캐릭터 | 캐릭터 레벨·EXP·컨디션 조회 |
| 자동감지 | GPS 자동 도착감지 모드 On/Off |
| 조용히 | 캐릭터 선톡(능동 메시지) On/Off |

## 난이도 안내 문구 설계

기상청 API의 강수량·강수확률·적설 정보를 기준으로 단계를 나누고, 각 단계마다 여러 문구를 풀(pool)로 준비해 랜덤 노출 (매번 같은 문구로 질리지 않게):

| 단계 | 기준 | 문구 예시 (풀 중 랜덤 선택) |
|---|---|---|
| 평온 | 맑음/흐림 | "오늘은 무풍지대입니다", "평화로운 출근길입니다" |
| 주의 | 강수확률 60%↑ 또는 약한 비 | "우천 대비 태세 발령", "습도 주의보 발효" |
| 경계 | 강수량 3mm/h↑ | "제14차 도시 진입 작전 — 도보 구간 난이도 상승", "장마 전선 돌파 임무" |
| 위험 | 강수량 10mm/h↑ 또는 대설주의보 | "생존 모드 진입", "이것은 실전입니다" |

## 배지 시스템

조퇴·병가·휴가는 부정적 기록으로 다루지 않고, 회복·휴식·자기관리 계열 문구로 표현합니다.

| 배지 | 획득 조건 |
|---|---|
| 첫 번째 탈출 | 첫 퇴근 완료 |
| 월요일의 생존자 | 월요일 출근 5회 |
| 지각 없는 인간 | 정시 출근 10회 연속 |
| 환승의 지배자 | 대중교통 이동 30회 |
| 폭우 돌파 | 비 오는 날 출근 완료 |
| 설국열차 | 눈 오는 날 출근 완료 |
| 새벽의 개척자 | 오전 7시 이전 출근 |
| 칼퇴 수호자 | 정시 퇴근 5회 |
| 야근의 목격자 | 오후 10시 이후 퇴근 |
| 탈출 전문가 | 퇴근 100회 |
| 현명한 도망 | 조퇴 최초 등록 |
| 회복도 업무다 | 병가 최초 사용 |
| 자유를 찾은 자 | 휴가 최초 사용 |
| 장기 생존자 | 100일 동안 기록 유지 |
| 전설의 직장인 | 출퇴근 합계 1,000회 |

### 배지 조회 화면 예시
```
🏆 나의 생존 배지 8 / 24
✅ 첫 번째 탈출
✅ 월요일의 생존자
✅ 폭우 돌파
✅ 칼퇴 수호자
🔒 지각 없는 인간 7 / 10
🔒 탈출 전문가 42 / 100

배지 이름을 입력하면 상세 내용을 볼 수 있습니다.
```

## 캐릭터 성장 시스템 🥚

배지(특정 조건 수집형)와 별도로, **누적 활동량에 따라 성장하는 캐릭터**를 하나 더 둡니다. 타마고치처럼 매일 출퇴근을 완료할수록 캐릭터가 크는 재미 요소입니다.

### EXP 획득 기준
| 상황 | EXP |
|---|---|
| 출근/퇴근 완료 (기본) | +10 |
| 정시 출근/퇴근 보너스 | +5 |
| 폭우·폭설 등 고난이도 완료 보너스 | +10 |
| 연속 기록 보너스 (3일차부터) | +2 × 연속일수 (최대치 있음) |
| 결근 | 0 (컨디션 하락) |
| 조퇴·병가·휴가 | 0 (컨디션 영향 없음, 회복 취급) |

### 진화 단계
| 레벨 구간 | 단계명 | 이모지 |
|---|---|---|
| Lv.1~4 | 알 | 🥚 |
| Lv.5~9 | 새싹전사 | 🐣 |
| Lv.10~19 | 출근용사 | 🐤 |
| Lv.20~39 | 베테랑 직장인 | 🦅 |
| Lv.40+ | 전설의 생존자 | 🐉 |

레벨업에 필요한 EXP는 레벨이 오를수록 점증(예: 다음 레벨 필요 EXP = 현재 레벨 × 20)하도록 설계해 성장 속도가 자연스럽게 완만해지도록 합니다.

### 컨디션 게이지
- 결근 시 컨디션 하락 (●●●○○ 식 5단계 표시)
- 조퇴·병가·휴가는 컨디션에 영향 없음 (오히려 소폭 회복도 가능) — "회복은 부정적이지 않다" 원칙 반영
- 컨디션이 너무 낮으면(예: 1칸 이하) 캐릭터가 "지쳤어요" 상태 메시지와 함께 휴식을 권유하는 멘트 노출 (질책이 아닌 걱정 톤)

### "내캐릭터" 조회 화면 예시
```
🐤 출근용사 (Lv.14)
EXP 340/500
컨디션: ●●●●○ (80%)
다음 진화까지 Lv.20 (6레벨 남음)
```

### 레벨업(진화) 알림 예시
```
🎉 진화했습니다!
Lv.10 도달 — "출근용사"로 진화
🐣 → 🐤
```

## 캐릭터의 선톡 (능동 메시지) 💬

사용자가 명령어를 입력하지 않아도, 캐릭터가 평소 패턴을 기준으로 **먼저 말을 거는** 기능입니다. 각 상황마다 여러 멘트를 풀(pool)로 준비해 랜덤 노출합니다.

### 트리거 조건과 멘트 예시
| 트리거 | 조건 | 멘트 예시 (풀 중 랜덤) |
|---|---|---|
| 출근 지각 의심 | 최근 N회 평균 출발시각 +20분 경과했는데 "출근" 기록 없음 | "야, 너 출근 안 하냐?", "나 혼자 성장 못 하잖아, 빨리 나와" |
| 퇴근 안 함 | 최근 평균 퇴근시각 +1시간 경과했는데 "퇴근" 기록 없음 | "아직도 회사냐?", "칼퇴 수호자 배지는 물 건너갔네" |
| 연속기록 위기 | 연속 출근 기록 N일째인데 오늘 아직 미기록 (마감 임박) | "야 연속 {N}일째인데 오늘 안 하면 리셋이다?" |
| 하루 마무리 체크인 | 퇴근 기록 완료 후 저녁 정해진 시각 | "오늘 하루 어땠냐?", "고생했다, 내일 또 보자" |
| 컨디션 저하 | 컨디션 게이지 1칸 이하 | "너 요즘 좀 지쳐 보인다, 무리하지 마" |

### 알림 정책
- 사용자별로 하루 최대 발송 횟수 제한 (스팸처럼 느껴지지 않게, 예: 하루 3회 이내)
- 같은 트리거는 하루 1회만 발송 (반복 알림 방지)
- **"조용히" 명령어**로 선톡 기능 전체 On/Off 가능 (원치 않는 사용자 배려)
- 판단 기준 시각은 사용자 최근 N회(예: 최근 10회) 출퇴근 기록 평균으로 계산 (기록이 부족한 초기에는 선톡 비활성)

## 디스코드 연동 (성과 브로드캐스트)

실제 조작(명령어 입력, GPS 위치공유, 우회 제안 응답 등)은 **텔레그램에서만** 이루어지고, 디스코드는 **성과 결과만 단방향으로 받아보는 채널**입니다. 지금까지 만든 날씨운세봇·캘린더회고봇이 Discord Webhook으로 결과를 보내던 방식을 그대로 재사용합니다.

### 디스코드로 전송되는 이벤트
- 🏅 배지 획득
- 🎉 캐릭터 레벨업/진화
- 📊 주간·월간 통계 리포트 ("O월 생존 보고서")

### 디스코드로 보내지 않는 것
- 출근/퇴근 경로 안내, 우회 제안 등 실시간 상호작용 메시지
- GPS 위치 관련 정보 전체
- 캐릭터 선톡(잔소리성 멘트)

→ 위치·실시간 정보는 텔레그램 안에서만 처리하고, 디스코드는 "자랑거리"만 보이게 해서 프라이버시와 역할을 분리합니다.

### 연동 방식
- Discord Webhook URL로 결과 이벤트 발생 시 메시지 전송 (n8n의 기존 워크플로우와 동일한 패턴)

## 웹 대시보드 (검토 중, 스택 미확정)

캐릭터·배지·통계를 텍스트 메시지 대신 웹에서 이쁘게 볼 수 있는 대시보드 추가를 검토 중입니다. 아직 확정된 건 아니고, 아래 방향만 메모해둡니다.

- **FE**: Next.js
- **BE**: Node 또는 FastAPI 중 미정 — DB에서 데이터를 꺼내 구조화해서 전달하는 역할
- **DB**: Supabase
- 텔레그램 봇(출근/도착 명령어, GPS, 선톡 등)과의 역할 분담(대시보드가 봇을 대체하는지, 보조 화면으로 추가되는지)도 아직 미정
- 확정되는 대로 이 섹션을 구체화

## 통계 화면 예시
```
📊 8월 생존 보고서
출근 14회 · 퇴근 13회
정상 출근 12회 · 지각 2회
조퇴 1회 · 휴가 2일 · 결근 0회
평균 출근 시간 42분
평균 퇴근 시간 51분
최장 연속 기록 9일
획득 배지 8개
이번 달 생존율: 93%
```

## 핵심 규칙

- 출근 후 **도착**을 입력해야 출근 1회로 인정
- 같은 날 중복 기록 방지
- 휴가 등록일에는 출근 알림 중지 (해당일 "출근" 입력 시 안내 후 무시)
- 반차는 오전/오후 구분
- 기록 수정 및 삭제 가능
- 위치·근태 정보는 최소한으로 저장 (아래 "데이터 정책" 참고)
- 회사의 공식 근태 시스템이 아닌 **개인용 기록 봇**임을 최초 사용 시 명시
- 도착 없이 다음날 새 "출근" 입력 시 → 이전 미완료 기록은 자동으로 "미완료" 처리 후 새 기록 시작
- 결근은 캐릭터 컨디션 하락으로 이어지지만, 조퇴·병가·휴가는 컨디션에 영향을 주지 않음 (동일한 "회복 존중" 원칙을 배지·캐릭터 시스템에 일관 적용)

## 데이터 정책

- 집/회사 주소는 좌표로 변환 후 저장 (원본 주소 텍스트는 최소화)
- GPS 실시간 좌표(자동감지 모드)는 **처리 후 저장하지 않음** — geofence 판정에만 사용하고, 이동 완료 시점의 소요시간·지연여부 요약만 기록
- 캐릭터 EXP·레벨·컨디션은 사용자별로 누적 저장 (개인 식별 정보 아님)
- 개인 근태 기록은 본인 텔레그램 계정에만 연결, 제3자 공유 기능 없음

| 스케줄링 | APScheduler(Python) 또는 n8n Cron — 주기적(예: 10~15분 간격)으로 사용자별 패턴 체크 후 선톡 트리거 판단 |

## 확장 가능성 (2단계 이후)

- 📍 실시간 진행률 안내 ("절반 왔어요, 12분 남았어요") — GPS 자동감지 모드 위에 얹는 추가 기능
- 📍 경로 이탈 감지 및 안내
- 🔔 능동형 알림 — 평소 출근 시간 전 봇이 먼저 "오늘 조건 안내드릴까요?" 말 걸기
- 🎨 캐릭터 커스터마이징 (스킨/악세서리 등 꾸미기 요소)
- 🏢 여러 사용자를 지원하는 팀/회사 버전으로 확장 (사업화 시 B2B 근태관리 툴 가능성)
- 📈 배지/통계/캐릭터 성장 히스토리 시각화 (월별 트렌드 그래프)

## 주의사항

- ⚠️ Tmap/ODsay, 공공데이터포털 API 키는 환경변수(.env)로 관리하고 노출 금지
- ⚠️ 실시간 대중교통 지연 정보는 제공 API의 정확도에 따라 오차 있을 수 있음
- ⚠️ GPS 기능은 사용자가 매번 위치 공유를 수동으로 켜야 함 (자동 상시 추적 아님)
- ⚠️ 회사의 실제 근태·인사 시스템을 대체하지 않는 개인용 도구임을 명확히 안내
