# 과제 미루기 사주 🔮

## 프로젝트 개요

**과제 미루기 사주**는 학생들이 자신의 과제 상황을 입력하면 Gemini AI를 활용하여 재미있고 신랄한 운세를 제공하는 웹 애플리케이션입니다.

## 목표 및 의도

- 📚 과제 미루기에 대한 상황을 재미있게 표현
- 🎯 AI를 활용한 개인화된 콘텐츠 생성
- 😄 사용자에게 웃음과 함께 현실을 깨닫게 함

## 핵심 기능

### 1. 동적 입력 시스템
- **선택식**: 사전 정의된 옵션 선택
  - 마감까지: 오늘, 내일, 3일 이내, 일주일 이상
  - 진행률: 0%, 조금, 절반, 거의 끝남
  - 상태: 아직 할 만함, 피곤함, 매우 피곤함, 유튜브 보는 중

- **직접 입력**: 사용자의 구체적인 상황 입력
  - 마감 시간 직접 입력 (예: "3시간 남음", "내일 오전 9시")
  - 상태 한마디 입력 (예: "손목이 아프지만 코딩은 해야함")
  - 과제 주제 입력 (예: "C++ 게임 엔진", "데이터베이스 팀 프로젝트")

### 2. AI 기반 운세 생성
Gemini API를 활용하여 다음 항목을 자동 생성:
- **미루기 위험도**: 0~100% 수치
- **제출 성공률**: 0~100% 수치
- **밤샘 가능성**: 매우 높음/높음/중간/낮음
- **교수님 자비운**: 상황을 반영한 재미있는 코멘트 (3-4줄)
- **지금 당장 할 일**: 구체적이고 실용적인 조언
- **교수님의 한마디**: 신랄하고 재미있는 한마디
- **한 줄 운세**: 전체 상황을 요약한 창의적인 문구

### 3. 개인화 및 창의성
- 과제 주제, 사용자 상태 등 모든 입력이 운세에 반영
- Gemini AI의 창의적인 언어 생성 능력 활용
- 기술 용어, 상황 맥락을 활용한 재미있는 표현

## 기술 스택

### 백엔드
- **Framework**: Flask 3.1.3
- **AI**: Google Gemini API
- **Environment**: Python 3.10+

### 프론트엔드
- **HTML5 + CSS3 + Vanilla JavaScript**
- **그래디언트 배경, 부드러운 애니메이션, 반응형 디자인**

### API 통신
- **기술**: REST API (POST 요청)
- **데이터 형식**: JSON
- **응답 처리**: JavaScript 동적 파싱

## 설치 및 실행

### 1. 필수 요구사항
- Python 3.10 이상
- Google Gemini API 키

### 2. 설치 방법

```bash
# 1. 프로젝트 디렉토리로 이동
cd portfolio

# 2. 필요한 패키지 설치
pip install -r requirements.txt

# 3. .env 파일 생성 (Gemini API 키 추가)
echo "GEMINI_API_KEY=your_api_key_here" > .env

# 4. Flask 서버 실행
python app.py

# 5. 브라우저에서 접속
# http://localhost:5000/study
```

### 3. 서버 설정
- 기본 포트: 5000
- 디버그 모드: 활성화
- 호스트: localhost

## API 엔드포인트

### POST /api/fortune
사용자 입력을 기반으로 운세를 생성합니다.

**요청 본문:**
```json
{
  "deadline": "3시간 남음",           // 마감까지 시간 (선택 또는 입력값)
  "progress": "0%",                    // 진행률 (선택값)
  "mood": "손목이 아픈데...",          // 상태 (선택 또는 입력값)
  "additionalInfo": "C++ 게임 엔진",  // 과제 주제
  "isCustomDeadline": true,            // 직접 입력 여부
  "isCustomMood": true                 // 상태 직접 입력 여부
}
```

**응답:**
```json
{
  "result": "미루기 위험도: 100%\n제출 성공률: 3%\n..."
}
```
