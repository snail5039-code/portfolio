### 5. 검색 평가 (검색기 비교)
`pipeline/evaluate_retrievers.py` - 검색 결과만으로 hit@k, MRR 등 채점

| 검색기 | 내 골든셋 73문제 MRR | 제공 골든셋 267문제 MRR |
|---|---|---|
| Similarity | 0.782 | 0.837 |
| MMR | 0.765 | 0.832 |
| BM25 | 0.679 | 0.813 |
| **Hybrid** | **0.809** | **0.839** |
| 표=MMR + 나머지=Hybrid 합치기 | 0.418 | 0.512 |

- 표 질문(267문제 중 48개)만 보면 **MMR이 가장 좋음** (hit@5 0.979, MRR 0.856)
- 두 결과를 합치면 매번 표 청크가 1위로 올라와 크게 나빠짐
- **결정: 표 질문이면 전체 청크 MMR, 아니면 Hybrid** (질문마다 하나를 골라 씀)
- ※ 위 숫자는 표 버그 수정 전 데이터 기준

### 6. RAG 에이전트
- `pipeline/retriever.py`: 검색 툴 `search(query, is_table, domain)` - 표 질문이면 MMR, 아니면 Hybrid
- `pipeline/agent.py`: `create_agent`
  - 검색 최대 3회 (`ToolCallLimitMiddleware`로 강제)
  - 구조화 출력: 답변/보류, 답변, 근거 판단 이유, 근거(chunk_id·파일·쪽·원문)
  - 실행 기록 저장: `output/runs/agent_runs.jsonl`
- 질문 3개로 확인: 답변(1회 검색), 재검색 후 답변(2회), 문서에 없는 질문 보류(3회)
