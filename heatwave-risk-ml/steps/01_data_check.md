# Step 1. 데이터 확인

## 목표

사용할 CSV 2개가 정상인지 확인한다.

## 할 일

- `data/raw/2025/heat_illness_2025_unified.csv` 불러오기
- `data/raw/2025/OBS_ASOS_DD_20260830192528.csv` 불러오기
- 컬럼명, 행 수, 날짜 범위 확인
- 결측치 개수 확인
- 온열질환 데이터에서 `daily_national` 행만 우선 사용

## 산출물

- 데이터 기본 정보 정리
- 사용할 컬럼 목록

## 확인 기준

- 온열질환 기간: `2025-05-15 ~ 2025-09-25`
- 기상 데이터도 같은 기간으로 자를 수 있어야 함
- 날짜별 온열질환자 수 합계가 `4,460명`이어야 함
