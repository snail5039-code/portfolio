# Step 2. 데이터 전처리

## 목표

머신러닝 학습에 사용할 하나의 데이터셋을 만든다.

## 할 일

- 온열질환 데이터에서 날짜별 전국 환자 수 추출
- 기상 데이터에서 `2025-05-15 ~ 2025-09-25`만 선택
- 날짜 컬럼 형식 통일
- 기상 데이터를 날짜별 전국 평균으로 집계
- 온열질환 데이터와 기상 데이터 병합
- 결측치 처리

## 사용할 feature

- 평균기온
- 최고기온
- 최저기온
- 일강수량
- 평균 풍속
- 평균 상대습도
- 합계 일조시간
- 합계 일사량

## target

- 날짜별 온열질환자 수
