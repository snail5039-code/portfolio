# Step 6. Streamlit 앱 구현

## 목표

모델 결과를 입력형 예측 서비스와 분석 대시보드로 보여준다.

## 화면 구성

- 왼쪽 입력 영역
- 상단 위험도 요약 카드
- 실제값 vs 예측값 그래프
- 기상 변수 중요도 그래프
- 연령별/발생시간별 현황 그래프

## 입력값

- 날짜
- 지역
- 나이
- 외출 예정 시간
- 예상 외출시간
- 평균기온
- 최고기온
- 평균 상대습도
- 평균 풍속

## 산출물

- `app.py`
- `requirements.txt`
- Streamlit 실행 화면

## 디자인 기준

- 공공 안전 서비스 느낌
- 위험도는 초록/노랑/주황/빨강으로 구분
- 글씨는 크게, 정보는 단순하게 표시
