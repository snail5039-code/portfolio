# 모델별 분석 보고서와 그래프

- 00_통합_분석보고서.pdf / .hwpx: 전체 연령과 65세 이상 모델을 각각 독립된 파트로 묶은 통합본

## 그래프

각 모델 폴더에 PNG 6개를 개별 저장했습니다. 전체 연령과 고령자 그래프를 섞지 않고 사용합니다.

1. 날짜별 환자 수
2. 일일 환자 수 분포
3. 최고기온 산점도
4. 기상 변수 상관계수
5. 저장된 주 모델의 변수 중요도
6. 연도 평가용 모델의 2025년 실제값·예측값

05는 저장된 주 모델, 06은 2022~2024년으로 따로 학습한 연도 평가 모델에 해당합니다.
전체 연령 날짜별 그림은 감시기간 내 순서, 고령자 날짜별 그림은 실제 날짜 축입니다.
그래프 작성 과정에서 주 모델과 CSV는 변경하지 않았습니다. 06 그래프 생성용 고정 설정 재학습은 메모리에서만 실행했습니다.
HWPX 구조·그림 참조·PNG는 확인했지만 한글 프로그램의 실제 페이지 렌더링은 확인하지 못했습니다.
