### 연도별 평가와 해석

- `model/model_year_test.py`, `model/model_year_test_elderly65.py`는 2022~2024년 학습 → 2025년 평가 실험이다. 서비스에 추가할 세 번째 모델이 아니다.
- 전체 연령 연도 평가: R² 0.686, MAE 13.128, RMSE 23.960.
- 고령자 최근 연도 평가: 학습 R² 0.970, 2025년 R² 0.687, MAE 4.174, RMSE **7.687**. 교차검증 R² 0.480.
- 고령자 연도 실험 설정은 트리 200개, 깊이 20, 최소 분기 3, 최소 리프 1, max_features="sqrt", random_state=42로 주 모델과 다르다.

- 무작위 평가와 연도 평가는 조건이 다르다. 점수만으로 직접 우열을 단정하지 않는다. 2025년 결과를 보며 실험했으므로 완전히 독립된 최종 검증이라고 부르지 않는다.
- R²는 정확도가 아니다. 모델 출력은 전국 일일 예상 환자/신고 건수이며 개인 발병 확률이 아니다.

1. 위 파일과 현재 Git 변경 상태를 확인한다. 오래된 계획의 EDA부터 다시 시작하지 않는다.

3. 데이터 사용 방침이 정해지면, 기존 파일을 덮어쓰지 않고 고령자 target과 기상값을 결합한 별도 학습 CSV를 만든다. 날짜 수, 결측치, 중복, 연도 합계와 입력 변수 누수를 검증한다.
4. 사용자와 한 단계씩 진행해 고령자 전용 모델을 학습·튜닝·평가한다. 기존 전 연령 모델 성능을 고령자 성능으로 재사용하지 않는다. 모델과 기상 컬럼을 별도 파일로 저장하고 재로드 검증한다.
5. 결과를 보고서에 반영하고, 예측 환자 수의 규칙 기반 등급 및 별도의 고령자 예방 안내를 결정한다. 분위수 경계와 등급은 아직 확정하지 않았다.
6. 이후 기상청 발효 특보/API 및 질병관리청 공식 예방 안내를 검토하고 Streamlit에 연결한다.

### 진행 방식과 해석 주의

- 사용자는 쉽고 짧은 한국어 설명, 한 단계씩 진행하는 방식을 선호한다. 현재 인수인계 요청을 모델 학습이나 보고서 수정 승인으로 확대하지 않는다.
- 65세 이상 모델도 전국 일일 신고 환자 수 예측이지 고령자 개인의 발병 확률/외출 안전 판정 모델은 아니다.
- 기존 전 연령 모델은 무작위 80:20 평가가 주 평가다. 연도 분리 평가는 보조 비교이며, 기존 최종 설정은 전체 연도의 무작위 학습 분리에서 선택되었다. 2025년 행을 연도 평가 학습에서 제외했다는 것과 튜닝까지 독립적이라는 것은 구분한다.
- 독립 연도 평가를 새로 수행한다면 튜닝에서도 평가 연도를 제외한다. 사용자에게 불필요하게 검증 용어를 반복하기보다 실제 학습/테스트 범위를 설명한다.
- R²를 정확도라고 쓰지 않는다. 위험등급을 의료적으로 검증된 기준이라고 표현하지 않는다.
- 기존 `analysis/eda_analysis.py`는 사용자 변경 상태다. 보존한다. 원본·기존 모델·보고서를 무단 덮어쓰거나 커밋/푸시하지 않는다.
- 점검 시 Git 상태: EDA 파일 수정, 새 원본/고령자 CSV 2개/처리 노트/`docs/분석보고서/00_통합_분석보고서.hwpx`는 미추적. 이 문서는 이번 인수인계 작성으로 추가 수정된다.

## 고령자 외출 안내 결정

현재 모델에는 개인별 나이, 외출 시간, 외출시간이 feature로 들어가지 않는다. 따라서 모델만으로 `이 고령자는 외출 가능`을 판정할 수 없다.

Streamlit에서는 다음을 분리해서 구현한다.

- 모델: 전국 예상 환자 수와 전국 위험등급 제공
- 규칙 기반 안내: 나이, 외출 시간대, 외출시간, 기온에 따라 고령자 외출 자제 수준 제공
- 안전 문구: 의료적 판단이 아닌 참고용 예방 안내임을 명시

`외출 가능`이라는 단정 대신 `비교적 위험이 낮음`, `주의`, `외출 자제 권고`, `외출 연기 권고`로 표현한다.
