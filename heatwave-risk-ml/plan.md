# 머신러닝 프로젝트 진행 계획

최신화: 2026-09-03. 세부 인수인계는 `HANDOFF.md`의 맨 위 최신 섹션을 따른다.

## 목표

2022~2025년 전국 일별 기상 입력 8개로 전체 연령과 65세 이상 환자 수를 각각 예측한다. 두 RandomForest 모델을 유지하고 이후 Streamlit에서 예측값과 설명을 제공한다.

## 모델 및 평가

| 항목 | 전체 연령 | 65세 이상 |
| --- | --- | --- |
| 학습 CSV | `data/processed/train_dataset.csv` | `data/processed/train_dataset_elderly65_2022_2025.csv` |
| 저장 모델 | `model/saved/heat_patient_model.pkl` | `model/saved/heat_patient_elderly65_model.pkl` |
| 무작위 테스트 R² | 0.846 | 0.837 |
| 무작위 테스트 MAE / RMSE | 9.700 / 14.871 | 3.209 / 4.917 |

고령자 저장 주 모델은 무작위 분할 학습 428일로 학습한 모델이다. 연도 평가의 고령자 모델은 설정이 다른 보조 실험이다. 무작위 평가와 연도 평가를 동일 조건으로 비교하지 않는다. R²는 정확도가 아니다.

## 다음 진행 순서

1. **API 받아오기**: Open-Meteo Weather Forecast API로 오늘·미래 날짜의 기상값 8개를 받는다. 전국 관측지점에 맞춰 조회·평균을 계산하고, 단위·컬럼 순서를 학습 데이터와 맞춘다.
2. **화면 만들기**: 사용자가 예시처럼 간단한 Streamlit 코드를 직접 작성한다. 대상·날짜·외출 시간을 입력받아 모델 예측 → 등급 → 해석·외출 안내를 표시한다.
3. **연결 확인**: 대상·날짜·외출 시간을 바꾸면 결과가 제대로 바뀌는지 확인한다. 여기까지 첫 버전 완성 범위로 정한다.

사용자가 직접 코드를 작성하고 실행하므로 짧은 설명과 한 단계씩 진행한다. 등급 경계는 확정했으며 재학습은 현재 다음 작업이 아니다. Open-Meteo는 서울 좌표의 3일치 예보 8개 수신을 확인했지만 프로젝트에는 아직 연결하지 않았다. 예보값으로 예측했을 때의 모델 성능 평가는 이후 별도로 진행한다.

## 작성과 학습 방식

- 사용자가 보여준 자동차 연비 Streamlit 예시처럼 간단한 코드로 작성한다.
- `모델 불러오기 → 입력받기 → 예측 버튼 → 결과·해석 출력`부터 만들고 필요한 기능만 하나씩 추가한다.
- 짧은 코드와 쉬운 한국어 주석을 사용하며, 설명을 요청하면 대화창에 주석을 붙인 코드로 보여준다.
- `설명 → 사용자 직접 작성 → 실행 결과 확인` 순서로 진행한다. 요청 전에 복잡한 구조나 추가 기능을 미리 구현하지 않는다.

## 자료와 표현의 한계

고령자 원본과 공식 연보의 2022~2024년 합계 차이는 미해결 상태로 유지한다. 모델 출력은 전국 일일 예상 환자/신고 건수다. 프로젝트에서 정한 예측값 등급을 공식 폭염특보나 개인 발병 확률·외출 안전 판정으로 표현하지 않는다.
