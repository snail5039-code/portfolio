# HyukForge — 디자인 시스템

작성일: 2026-08-17 · 톤: **워크벤치(공방)**

## 1. 무엇을 피하는가

이 문서의 절반은 금지 목록이다. 기본값대로 만들면 "AI가 뽑아준 랜딩페이지"처럼 보이기 때문이다.
아래 항목은 **예외 없이 금지**한다.

| 금지 | 이유 | 대신 |
| --- | --- | --- |
| 3D 아이소메트릭 일러스트, 떠다니는 아이콘 렌더 | AI 생성 랜딩페이지의 1순위 지문 | 실제 앱 화면 캡처 |
| 보라·인디고 그라데이션 (`#6C5CE7` 계열) | 취향이 아니라 기본값으로 보임 | 앰버 단색 |
| 모든 그라데이션 배경, 네온 글로우, 컬러 그림자 | 위와 같음 | 1px 선과 여백 |
| 이모지 아이콘 타일 (💼 🎮 🔧 ⚗️) | 성의 없어 보임 | 모노스페이스 한 글자 또는 실제 앱 아이콘 |
| 균등한 카드 4개 반복 그리드 | 위계가 사라짐 | 대표 1개는 크게, 나머지는 표 |
| 어두운 방의 개발자 스톡 사진 | 내용이 0 | 지우고 개발 기록을 넣는다 |
| 기술 스택 로고 그리드 | 채움 섹션 | 지운다 |
| "One developer. Built from ideas." 류의 슬로건 | 정보가 없음 | 구체적인 문장 |
| 한/영 2단 적재 헤드라인 | 번역기 결과물처럼 보임 | 한 언어만 |
| 3개짜리 밸류 프로포지션 (BUILD / SHIP / IMPROVE) | 전형적 | 실제 숫자 4개 |

**한 줄 원칙: 장식을 더해서 좋아 보이게 하지 말고, 진짜 정보를 넣어서 좋아 보이게 한다.**

## 2. 색

단 세 가지 + 회색 계열. 강조색은 **하나뿐**이다.

```css
--color-bg:       #060606;   /* 바탕 — 로고 배경과 동일값 */
--color-panel:    #0B0B0A;   /* 카드·창 안쪽 */
--color-ink:      #EDEAE4;   /* 본문 (순백 아님 — 살짝 따뜻하게) */
--color-mute:     #A8A29A;   /* 보조 텍스트 — 바탕 대비 8.0:1 */
--color-dim:      #837E75;   /* 라벨, 비활성 — 바탕 대비 5.0:1 */
--color-line:     #2A2723;   /* 기본 구분선 */
--color-edge:     #3B3630;   /* 강한 테두리 */
--color-amber:    #E29B2E;   /* 강조 — 유일한 유채색 */
--color-amber-hi: #EEA430;   /* 강조 hover */
--color-on-amber: #12100C;   /* 앰버 배경 위 글자 */
```

**색은 로고에서 뽑았다, 지어내지 않았다.**
`node scripts/brand.mjs analyze`가 원본 로고의 픽셀을 읽어 배경색과 앰버 분포를 출력한다.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 바탕 | `#060606` | 로고 PNG의 배경색 그대로. 다르면 로고를 올렸을 때 사각형 이음매가 보인다. |
| 앰버 | `#E29B2E` | 로고 앰버 픽셀의 **중앙값**. 하이라이트(`#FFC428`)를 쓰면 실제보다 튄다. |
| 앰버 hover | `#EEA430` | 같은 분포의 밝은쪽(85퍼센타일). |

앰버는 바탕 대비 **8.4:1**로 본문 크기 글자에도 쓸 수 있다.

**보조 글자 대비는 WCAG AA(4.5:1)를 기준으로 잡는다.**
처음 값은 `--dim` 이 2.8:1 이라 라벨이 사실상 보이지 않았다.
어두운 바탕에서 작은 모노 글자에 넓은 자간까지 겹치면 계산보다 더 안 읽힌다.
색을 바꿀 때는 눈으로 보지 말고 대비를 재고 바꾼다.

**분류별 보조색** (태그와 필터에만, 넓은 면적 금지)

```css
--c-office: #6E9E7A;   /* 사무용 — 차분한 초록 */
--c-games:  #C4563E;   /* 게임 — 벽돌색 */
--c-utils:  #7A8CA8;   /* 유틸리티 — 흐린 청회색 */
--c-web:    #A88A5E;   /* 웹앱 — 황토 */
--c-labs:   #8F7AA8;   /* 실험실 — 탁한 보라 */
```

**규칙**
- 앰버는 화면당 3~4곳까지. 그 이상 쓰면 강조가 아니게 된다.
- 분류색은 태그 테두리·글자에만. 배경을 칠하지 않는다.
- 다크 전용이다. 라이트 모드는 만들지 않는다 (선택이 아니라 정체성).

## 3. 글자

```css
--sans: Pretendard, -apple-system, "Segoe UI", "Malgun Gothic", sans-serif;
--mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

**모노스페이스를 쓰는 곳** — 이게 워크벤치 톤의 핵심이다.
버전 번호 · 파일 용량 · 날짜 · 플랫폼 · 분류 태그 · 섹션 라벨 · 버튼 · 통계 숫자.
사람이 읽는 문장은 전부 산세리프.

| 용도 | 크기 | 자간 | 색 |
| --- | --- | --- | --- |
| 히어로 제목 | `clamp(30px, 4.2vw, 50px)` / 1.18 | `-0.03em` | `--ink` |
| 섹션 제목 | 19px / 600 | `-0.01em` | `--ink` |
| 제품명 (표) | 14.5px / 600 | — | `--ink` |
| 본문 | 15px / 1.6 | — | `--mute` |
| 라벨 (mono, 대문자) | 11px | `0.14em` | `--dim` |
| 데이터 (mono) | 12px | — | `--mute` |
| 통계 숫자 (mono) | 23px / 500 | `-0.01em` | `--ink` |

## 4. 여백과 선

- 구분은 **1px 선**으로만 한다. 그림자·둥근 모서리·배경 대비를 쓰지 않는다.
- **`border-radius: 0`이 기본값이다.** 둥근 모서리를 쓰지 않는다.
- 섹션 위 여백 78px, 히어로는 92px.
- 최대 폭 1180px, 좌우 여백 28px.
- 표 행 높이는 넉넉하게 (상하 15px). 촘촘한 표는 데이터 대시보드처럼 보인다.

## 5. 레이아웃 규칙

### 비대칭을 강제한다

- 히어로: `44fr : 56fr` (반반 금지)
- 대표 제품: `58fr : 42fr`
- 소개: `52fr : 48fr`

정확히 반씩 나뉜 그리드는 기계적으로 보인다. 항상 한쪽을 크게 한다.

### 제품 나열 방식

```
┌───────────────────────────────────────────┐
│  대표 제품 1개 — 스크린샷 + 설명 + 사양표   │   크게
└───────────────────────────────────────────┘
┌───────────────────────────────────────────┐
│  이름 │ 분류 │ 버전 │ 크기 │ 날짜 │ 받기   │   표로
│  이름 │ 분류 │ 버전 │ 크기 │ 날짜 │ 받기   │
└───────────────────────────────────────────┘
```

카드를 4개씩 반복하지 않는다. **표는 소프트웨어 카탈로그의 언어**이고, 카드 그리드는 쇼핑몰의 언어다.

## 6. 컴포넌트

### 로고

HF 모노그램(각진 H와 F가 앰버 사선을 공유) + `HYUKFORGE` 워드마크 + `INDEPENDENT SOFTWARE STUDIO` 태그라인.
원본은 `public/brand/lockup.png` (1254×1254). `node scripts/brand.mjs build`가 여기서 조각을 뽑아낸다.

| 파일 | 크기 | 쓰는 곳 |
| --- | --- | --- |
| `public/brand/lockup.trim.png` | 976×518 | 소개 페이지, OG 이미지, 큰 자리 |
| `public/brand/mark.png` | 458×331 | 네비바, 푸터, 로딩 화면 |
| `public/brand/wordmark.png` | 950×88 | 마크와 따로 쓸 때 |
| `app/icon.png` | 458×458 | 파비콘 (Next.js가 자동 인식) |

**규칙**

- 마크에는 금속 질감 그라데이션이 들어 있다. **이건 로고라서 §1의 그라데이션 금지에서 예외다.** UI 요소에 같은 질감을 흉내 내지 않는다.
- **28px 미만으로 줄이지 않는다.** 그 아래에서는 사선 디테일이 뭉개진다. 더 작은 자리가 필요하면 앰버 사선만 남긴 단순형을 따로 만든다.
- 로고 위에 글자를 얹거나, 색을 바꾸거나, 늘이지 않는다.
- 배경이 `#060606`으로 박혀 있으므로 **`--color-bg` 위에서만 쓴다.** `--color-panel` 위에 올리면 사각형이 드러난다.
- 태그라인(`INDEPENDENT SOFTWARE STUDIO`)은 영어 고정이다. 10개 언어로 번역하지 않는다.

### 버튼

```
기본:  1px 테두리(--line-2), 배경 없음, mono 12px, 자간 0.08em, 패딩 11×20
강조:  앰버 배경, 글자 #12100C, 굵게
hover: 기본은 테두리를 --ink로, 강조는 배경을 --amber-h로
```

둥근 모서리·그림자·transform 애니메이션 없음.

### 앱 화면 프레임

제품 스크린샷은 창 프레임 안에 넣는다.

- 제목 표시줄: 9×9 **정사각** 세 개 (macOS 원형 점 금지 — Windows 앱이 대부분이다) + 파일 경로를 mono로
- 하단 상태 표시줄: 왼쪽에 상태, 오른쪽에 `v1.2.0 · Windows 10/11`
- 스크린샷이 아직 없으면 CSS로 만든 UI 모형을 쓴다. 3D 렌더나 추상 도형으로 때우지 않는다.

### 태그

```
mono 11px · 자간 0.1em · 1px 테두리 · 패딩 3×8 · 배경 없음
```

### 사양표

`dt`(--dim) 82px + `dd`(--mute), 행마다 하단 1px 선. 무료 표기만 앰버.

### 개발 기록 행

```
[ 2026.08.16 ]  [ File Organizer ]  확장자 없는 파일이 <기타>로 가던 문제 수정.
     mono/dim         mono/mute              sans/ink 14px
```

3열 그리드 `104px 118px 1fr`. 모바일에서는 세로로 쌓는다.

## 7. 글쓰기 규칙

디자인만큼 톤을 결정한다.

- **1인칭으로 쓴다.** "제공합니다" 대신 "만들었습니다", "고칩니다".
- **만든 이유를 한 문장 넣는다.** "다운로드 폴더가 감당이 안 돼서 만들었습니다."
- **빈 형용사 금지**: 혁신적인, 강력한, 스마트한, 완벽한, 최적화된.
- **알려진 문제를 적는다.** "WebP 변환이 느린 건 알고 있고 다음 버전에서 고칩니다."
- **숫자는 진짜만.** 다운로드가 12회면 12를 쓴다. 안 쓸 거면 아예 감춘다.
- 느낌표를 쓰지 않는다.

## 8. 반응형

| 폭 | 처리 |
| --- | --- |
| ≥ 900px | 비대칭 2열 유지 |
| < 900px | 전부 1열, 통계는 2×2, 제품 표는 가로 스크롤 (`overflow-x: auto`) |

제품 표를 모바일에서 카드로 바꾸지 않는다. 가로 스크롤이 정직하고, 카드로 변신하면 다른 사이트처럼 보인다.
