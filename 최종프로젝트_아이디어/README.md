# 최종 미니프로젝트 아이디어 초안

사주챗봇 / 날씨운세봇 / 캘린더 회고봇 / API 가이드봇 등 그동안 만든 미니 프로젝트 경험을 바탕으로 정리한 최종 프로젝트 후보 아이디어 노트입니다.

## 후보 아이디어

1. **만능 라이프 비서봇 (통합형)** — 사주, 날씨, 캘린더 회고, API 조회 등을 하나의 텔레그램+디스코드 봇으로 통합
2. **과제 미루기 사주 — 텔레그램 알리미 버전** — 기존 웹앱(Flask + Gemini)을 능동형 텔레그램 봇으로 재구성
