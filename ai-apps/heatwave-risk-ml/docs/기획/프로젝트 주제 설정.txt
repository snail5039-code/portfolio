머신러닝 PJ 프로젝트 주제선정

● 프로젝트 주제

기상 및 온열질환 데이터를 활용한 고령자 폭염 외출 위험도 예측

기상청의 기상 데이터와 질병관리청의 온열질환 발생 데이터를 분석하여 폭염 시 고령자의 외출 위험도를 예측하고, 위험한 시간대의 외출을 사전에 알려주는 서비스를 개발한다.

프로젝트는 공공데이터를 활용하여 고령자의 안전한 외출을 지원하는 서비스를 개발한다는 가정하에 진행할 예정.

● 프로젝트 주제 선정 이유

최근 여름철 폭염과 이상고온 현상이 지속되면서 고령층의 온열질환 발생 위험이 증가하고 있다.

기존 날씨 서비스는 기온이나 폭염특보 중심으로 정보를 제공하기 때문에 실제 고령자가 특정 시간에 외출했을 때의 위험 정도를 직관적으로 판단하기 어렵다.

과거 기상정보와 온열질환 발생 데이터를 분석하여 어떤 기상조건에서 온열질환 발생 위험이 증가하는지 확인하고자 한다.

머신러닝을 활용하여 현재 및 미래 기상정보를 기반으로 고령자의 외출 위험도를 예측하고 안전한 외출 의사결정을 지원하고자 한다.

분석 순서

1. 현황 분석

질병관리청 온열질환 데이터 분석

연도별 온열질환 발생 현황

지역별 온열질환 발생 현황

고령층 온열질환 발생 비율 분석

기상청 과거 기상 데이터 분석

기상조건 변화에 따라 온열질환 발생자가 어떻게 변화하는지 분석한다.

2. 데이터 결합 및 상관관계 분석

질병관리청 온열질환 데이터와 기상청 과거 기상 데이터를 날짜 및 지역을 기준으로 결합한다.

이를 통해 다음과 같은 관계를 분석한다.

기온과 온열질환 발생의 관계

습도와 온열질환 발생의 관계

최고기온과 온열질환 발생의 관계

기상요소별 온열질환 발생 영향 분석

3. 머신러닝 위험도 예측

결합된 데이터를 이용하여 폭염 시 온열질환 발생 위험도를 예측하는 머신러닝 모델을 개발한다.

사용 모델 후보

Decision Tree

Random Forest

Gradient Boosting

XGBoost

LightGBM

각 모델의 성능을 비교하여 최종 모델을 선정한다.

4. 해결방법 제시

학습된 머신러닝 모델과 실시간 기상 API를 연결하여 사용자가 외출 예정 정보를 입력하면 위험도를 제공한다.

● 최종 목표

과거 기상정보와 온열질환 발생 데이터를 머신러닝으로 분석하여 폭염 시 고령자의 외출 위험도를 예측하고, 위험할 경우 외출 자제 및 무더위쉼터 등의 안전정보를 제공하는 서비스를 구현한다.
